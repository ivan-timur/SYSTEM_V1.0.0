# گزارش ارتقای SYSTEM v8.0.0 — REBIRTH CORE

## تغییرات واقعی این نسخه
- افزودن `js/rebirth-core.js` با API افزایشی `window.SYSTEMRebirth` برای ثبت رویدادهای محلی، جلوگیری از ثبت تکراری بر اساس شناسه، نگهداری حداکثر ۲۰۰۰ رویداد و خواندن تاریخچه محدود.
- حذف کلیدهای حساس رایج از payload رویدادها پیش از ذخیره‌سازی.
- افزودن `css/rebirth-core.css` به مجموعه CSS تجمیع‌شونده: focus قابل مشاهده، تعاملات hover ملایم و پشتیبانی از `prefers-reduced-motion`.
- هماهنگ‌سازی نسخه در `VERSION`، `package.json`، ماژول نسخه، Service Worker و برنامه قدیمی.
- اصلاح تست نسخه‌ای که نسخه 7.8.0 را ثابت فرض می‌کرد.

## سازگاری و محدودیت‌ها
- موتور جدید افزایشی است و کلیدهای ذخیره‌سازی قدیمی را تغییر نمی‌دهد؛ رویدادها تنها زمانی ثبت می‌شوند که API جدید فراخوانی شود.
- این دفترچه محلی به‌تنهایی جایگزین تراکنش‌های اقتصادی XP/Coins یا همگام‌سازی سرور نیست.
- تست‌های Playwright مرورگر اجرا نشدند: دستور نصب‌شده در این محیط با `playwright test` سازگار نبود. بنابراین نتیجه تست واقعی مرورگر/موبایل هنوز تأیید نشده است.
