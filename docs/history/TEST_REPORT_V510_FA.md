# گزارش آزمون SYSTEM v5.10.0

## نتیجهٔ آزمون‌های اجراشده

- `npm test` موفق: **۱۸۹ بررسی Smoke/Unit** و اعتبارسنجی ۲۲ فایل JSON.
- آزمون ذخیره‌سازی و اعتبارسنجی پشتیبان: **۲۰ بررسی موفق**.
- آزمون snapshot خودکار: **۵ بررسی موفق**.
- ممیزی امنیت، نسخه، ساخت CSS و precache: **۵۷ بررسی موفق**.
- مجموع بررسی‌های ایستا: **۲۷۱**.
- ساخت نهایی CSS از ۳۴ فایل منبع موفق بود و فایل زمان اجرا هیچ `!important` ندارد.
- Service Worker برای نسخهٔ 5.10.0 از ۹۹ منبع محلی cache می‌سازد.

## محدودیت آزمون مرورگر

آزمون‌های Playwright برای Status/Quest و رفتارهای تازهٔ Skill Tree در پروژه موجود اند، اما در این محیط اجرا نشدند؛ پکیج `@playwright/test` در وابستگی‌های نصب‌شده موجود نیست. بنابراین تعامل واقعی مرورگر، ظاهر رندرشده و نمای تلفن در این اجرا تأیید تصویری نشده‌اند. برای اجرای محلی از دستورهای زیر استفاده شود:

```bash
npm install
npx playwright install chromium
npm run test:e2e
```
