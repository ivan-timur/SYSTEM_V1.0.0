# گزارش ارتقای بخش Rewards — SYSTEM v8.5.4

## تغییر اصلی
- رفع ایراد مسیر‌دهی دسته‌بندی‌ها در Rewards.
- تب «Mission Rewards» اکنون پاداش‌های روزانه و پاداش‌های مأموریت را یک‌جا نشان می‌دهد.
- تب «Achievement Rewards» فقط دستاوردها را نشان می‌دهد.
- تب «Special Rewards» فقط پاداش‌های ویژه را نشان می‌دهد.
- شمارنده‌های آمادهٔ دریافت روی تب‌ها با دسته‌بندی واقعی هر تب هماهنگ شده‌اند.

## سازگاری و ایمنی داده‌ها
- شناسه‌های پایدار پاداش‌ها تغییر نکرده‌اند؛ ادعاهای ذخیره‌شده و داده‌های قدیمی باید حفظ شوند.
- منطق اصلی دریافت پاداش، تراکنش XP/سکه، تاریخچه، Mystery Vault، شانس‌ها و pity counter بازنویسی نشده است.
- نسخهٔ برنامه، package، manifest، نسخهٔ runtime و service worker با اسکریپت build از VERSION همگام شده‌اند.
- CSS نهایی دوباره ساخته شد و service worker شامل 128 ورودی precache است.

## اعتبارسنجی
- `npm run build` — موفق.
- `npm run test:static` — موفق؛ تمام مجموعه‌های تست ایستا عبور کردند، از جمله 42 بررسی Rewards Ascension.

## یادداشت
این ارتقا یک باگ واقعی در دسته‌بندی و دسترسی به پاداش‌ها را اصلاح می‌کند و عمداً به ذخیره‌های کاربر یا شناسه‌های پاداش دست نمی‌زند.
