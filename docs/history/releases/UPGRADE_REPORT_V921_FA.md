# گزارش اصلاح رابط SYSTEM v9.2.1

## مشکل مشاهده‌شده در تصویر
در نسخهٔ 9.2.0، قانون عمومی دکمه‌های داخل `.chat-input` عرض و ارتفاع ثابت اعمال می‌کرد. این قانون با نوار ابزار فشردهٔ AI در تعارض بود؛ دکمه‌های کوچک عرض کافی برای برچسب‌ها نداشتند و نام ابزارها روی یکدیگر می‌افتادند یا از فضای خود بیرون می‌زدند.

## اصلاحات انجام‌شده
- تنظیم اندازهٔ دکمه‌های نوار AI با انتخابگر دقیق‌تر، برای جلوگیری از غلبهٔ قانون قدیمی دکمه‌های چت.
- در صفحه‌نمایش‌های موبایل تا عرض 600 پیکسل، تبدیل شش گزینهٔ ابزار به دکمه‌های آیکونی 34×34 پیکسل با فاصلهٔ ثابت و برچسب‌های دیداری مخفی.
- حفظ نام‌های دسترس‌پذیری و عنوان هر ابزار؛ بنابراین ابزارهای Study Analyzer، Code Helper، Math Solver، Idea Generator، Goal Assistant و Study Desk همچنان قابل شناسایی‌اند.
- در دسکتاپ، نگه‌داشتن برچسب‌های متنی با عرض طبیعی تا حد جلوگیری از فشردگی و هم‌پوشانی.
- حفظ کادر پیام، شمارنده‌ها، اتصال ابزارها به promptهای اصلی و رفتار Study Desk و Status Command Deck.
- به‌روزرسانی نسخه به 9.2.1 و بازسازی CSS و Service Worker با پیش‌بارگذاری 112 منبع.

## اعتبارسنجی
- `npm test`: موفق؛ همهٔ آزمون‌های ایستای پروژه از جمله آزمون جدید چیدمان موبایل گذشتند.
- `npm run doctor`: موفق؛ فایل‌های runtime و metadata نسخه سازگار تشخیص داده شدند.
- بررسی syntax فایل‌های JavaScript منتخب: موفق.
- آزمون واقعی بصری در مرورگر اجرا نشد، چون وابستگی Playwright در محیط نصب نیست. بنابراین برای اطمینان نهایی، نسخه را روی موبایل باز کنید و نوار ابزار AI را بررسی کنید.
