# گزارش ارتقای SYSTEM v7.0.0 — تمرکز تطبیقی

## هدف
ارتقای نقشه راه از فهرست کارها به راهنمای اقدام بعدی، بدون تغییر در موتور XP/سکه/رتبه یا کلیدهای ذخیره‌سازی قبلی.

## تغییرات
- کارت «گام پیشنهادی بعدی / NEXT BEST ACTION» به نقشه راه اضافه شد.
- پیشنهاد بر اساس قواعد شفاف و قابل توضیح انتخاب می‌شود: ۱) کار عقب‌افتاده، ۲) نزدیک‌ترین مهلت، ۳) اولویت ثبت‌شده، ۴) کار در حال انجام، ۵) قدیمی‌ترین گام ثبت‌شده.
- دکمه «نمایش این گام / Focus this task» جست‌وجو را روی همان گام تنظیم می‌کند.
- اگر همهٔ گام‌ها تکمیل شده باشند، حالت خالی مناسب نشان داده می‌شود.
- طراحی کارت واکنش‌گرا است و برای صفحه‌های باریک به چیدمان عمودی تبدیل می‌شود.
- هیچ پاداش XP/سکه‌ای به نقشه راه اضافه نشده و ساختار داده و تم‌های قبلی حفظ شده‌اند.

## محدودیت‌ها
این پیشنهاددهنده الگوریتم قاعده‌محور محلی است، نه هوش مصنوعی آنلاین و نه برنامه‌ریز تقویمی کامل. اطلاعات نقشه راه همچنان محلیِ مرورگر است و برای انتقال دستگاه باید از خروجی/ورودی JSON استفاده شود.
