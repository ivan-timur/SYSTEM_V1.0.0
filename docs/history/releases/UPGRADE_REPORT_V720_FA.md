# گزارش ارتقای SYSTEM v7.2.0 — تحلیل و اولویت‌بندی نقشهٔ راه

## هدف
ارتقای قابل‌آزمایش موتور تحلیل نقشهٔ راه، بدون تغییر در ساختار داده‌های ذخیره‌شده یا منطق پاداش‌های XP و Coins.

## تغییرات
- محاسبهٔ درصد تکمیل کلی نقشهٔ راه.
- نمایش شمار جداگانهٔ کارهای عقب‌افتاده، دارای مهلت امروز و دارای مهلت در هفت روز آینده.
- محاسبهٔ شاخص فشار کاری شفاف از ۰ تا ۱۰۰ با سطح کم، متوسط یا زیاد. این شاخص ابزار برنامه‌ریزی است و پیش‌بینی علمی یا تشخیص خستگی نیست.
- ارائهٔ توصیهٔ بعدی قاعده‌محور: رسیدگی به عقب‌افتاده‌ها، تکمیل کارهای امروز، بازبینی کارهای متوقف، تمرکز بر اولویت بالا، شروع کوچک، برنامه‌ریزی گام بعدی یا ایجاد اولین کار.
- تحلیل‌ها فقط‌خواندنی هستند و وضعیت کارها، XP یا سکه‌ها را تغییر نمی‌دهند.
- گسترش آزمون‌های نقشهٔ راه برای محدودهٔ امتیاز، سطح فشار، درصد تکمیل، شمار مهلت‌ها و کد توصیه.

## سازگاری
- نسخه به 7.2.0 به‌روزرسانی شد.
- ساختار ذخیره‌سازی فعلی نقشهٔ راه تغییر نکرد.
- فایل‌های CSS و Service Worker از طریق اسکریپت‌های پروژه بازسازی شدند.

## محدودیت
این نسخه بر تحلیل نقشهٔ راه تمرکز دارد و بازطراحی کامل UI یا افزودن سرور/همگام‌سازی ابری نیست. شاخص‌ها بر اساس داده‌های ثبت‌شده محاسبه می‌شوند و نمی‌توانند کیفیت یادگیری واقعی را به‌تنهایی اندازه بگیرند.
