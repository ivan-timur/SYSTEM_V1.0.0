# گزارش اصلاح بخش Rewards — نسخه 8.5.5

## مشکل
با انتخاب یک تب مانند Special Rewards، کارت‌های دسته‌های دیگر ممکن بود همچنان دیده شوند؛ چون قواعد نمایشی CSS برای `.reward-card` می‌توانستند ویژگی استاندارد `hidden` را خنثی کنند.

## اصلاح
- قانون صریح و اولویت‌دار برای پنهان‌کردن کارت‌های دارای `hidden` به فایل‌های CSS مرتبط با Rewards افزوده شد.
- منطق فیلتر دسته‌ها در `js/rewards-plus.js` حفظ شد؛ هر کارت باید هم‌زمان با دسته فعال، جستجو و فیلتر وضعیت مطابقت داشته باشد.
- فایل‌های اصلی پروژه و دارایی‌ها حفظ شدند.

## بررسی
این اصلاح بر رفتار نمایش کارت‌ها تمرکز دارد. اجرای تست مرورگر واقعی در این محیط انجام نشده است؛ پس پس از بازکردن پروژه، تب‌های Mission Rewards، Achievement Rewards و Special Rewards را جداگانه آزمایش کنید.
