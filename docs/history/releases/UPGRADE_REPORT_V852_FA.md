# گزارش ارتقای SYSTEM 8.5.2 — جایزهٔ تصادفی روز

## قابلیت اضافه‌شده
در انتهای فهرست Daily Quest کارت ویژهٔ «Daily Prize / جایزه روز» اضافه شده است. با تکمیل هر شش مأموریت اصلی روزانه، سیستم به‌طور خودکار یک جایزهٔ تصادفی را انتخاب و در همان عملیات تکمیل ثبت می‌کند؛ به دکمهٔ Claim جداگانه نیاز نیست.

## صندوق‌های جایزه
انتخاب از یک مجموعهٔ وزنی با احتمال‌های جمعاً ۱۰۰٪ انجام می‌شود:

| رتبه | احتمال | XP | سکه |
|---|---:|---:|---:|
| Common — گنجینهٔ غبار ستاره‌ای | ۳۵٪ | ۱۶۰ | ۵۰ |
| Uncommon — گنجینهٔ مهتابی | ۲۸٪ | ۲۲۰ | ۷۰ |
| Rare — صندوق شفق قطبی | ۱۸٪ | ۳۲۰ | ۱۰۰ |
| Epic — گنجینهٔ سحابی | ۱۱٪ | ۵۰۰ | ۱۶۰ |
| Legendary — صندوق ستاره‌ای سلطنتی | ۶٪ | ۸۰۰ | ۲۶۰ |
| Mythic — تاج اسطوره‌ای | ۲٪ | ۱۴۰۰ | ۵۰۰ |

جایزه فقط XP بازیکن و سکه را افزایش می‌دهد؛ به‌صورت پنهانی XP یک شاخه یا مهارت را افزایش نمی‌دهد. همهٔ سطح‌های جایزه از پاداش ثابت قبلی (+۱۵۰ XP و +۵۰ سکه) بهترند.

## پایداری و محافظت
- جایزه و تاریخ روز محلی ذخیره می‌شوند؛ بارگذاری دوباره، باز کردن دوبارهٔ صفحه یا اجرای دوبارهٔ عملیات نباید جایزه را دوباره بدهد یا آن را دوباره انتخاب کند.
- پاداش Perfect Day نسخهٔ قبلی برای همان روز شناسایی می‌شود تا هنگام ارتقا پاداش تکراری پرداخت نشود.
- رکورد جایزه به بررسی صحت داده‌های Storage و Backup افزوده شده است.
- کارت با زبان انگلیسی و دری کار می‌کند، در موبایل جمع‌وجور می‌شود و تنظیم کاهش حرکت (Reduced Motion) را رعایت می‌کند.

## آزمون‌ها
- `npm test` با موفقیت اجرا شد: ساخت CSS و Service Worker، و تمام مجموعهٔ آزمون‌های ایستا و واحد از جمله ۳۳ بررسی مخصوص Daily Prize.
- بررسی سینتکس فایل‌های JavaScript موفق بود.
- آزمون تعاملی کامل در مرورگر واقعی در این محیط قابل تکمیل نشد؛ اجرای Chromium هدلس حتی روی یک صفحهٔ ساده هم متوقف می‌ماند. بنابراین نتایج گزارش‌شده مربوط به build، آزمون‌های ایستا، واحد، منطق پاداش، وضعیت قفل/نمایش کارت، ذخیره‌سازی و سازگاری Backup هستند؛ ادعای آزمون end-to-end مرورگر مطرح نمی‌شود.
