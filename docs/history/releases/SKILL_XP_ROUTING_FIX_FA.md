# گزارش اصلاح تخصیص XP مهارت‌ها — SYSTEM 8.3.1

## تغییرات

1. **شناسه مهارت صریح اولویت قطعی دارد.** اگر `skillId` ارسال‌شده وجود نداشته باشد یا به شاخه آماری دیگری تعلق داشته باشد، سیستم به حدس‌زدن از روی عنوان برنمی‌گردد و به آن گره XP نمی‌دهد.
2. **تطبیق عنوان سخت‌گیرانه‌تر شد.** عبارت کامل نام مهارت امتیاز بالاتری می‌گیرد؛ هم‌پوشانی یک واژه مانند «logic» یا «functions» دیگر برای تخصیص XP کافی نیست.
3. **موارد مبهم رد می‌شوند.** اگر دو گره تقریباً به یک اندازه محتمل باشند، هیچ گره‌ای به‌صورت تصادفی انتخاب نمی‌شود.
4. **پیش‌نیازها همچنان اجباری‌اند.** مسیر انتخاب‌شده از `getAvailableSkillPath` عبور می‌کند؛ گره قفل‌شده یا فرزندان آن پس از پیش‌نیاز تکمیل‌نشده XP نمی‌گیرند. پیشرفت در والدهای مجاز حفظ می‌شود.
5. **تست‌های رگرسیون افزوده شد.** تطبیق دقیق، عنوان عمومی، شناسه ناموجود و شناسه متعلق به شاخه اشتباه آزمایش می‌شوند.

## رفتار مورد انتظار

- عنوانی مانند `Algebra I practice` می‌تواند به گره Algebra I نگاشت شود.
- عنوان عمومی یا نامشخص می‌تواند XP بازیکن/شاخه بگیرد، اما به گره مهارتی نامرتبط XP نمی‌دهد.
- شناسه مهارت اشتباه به مهارت دیگری منتقل نمی‌شود.
- پیش‌نیازهای Skill Tree با عنوان یا شناسه صریح دور زده نمی‌شوند.
