# گزارش ارتقای SYSTEM v6.3.1 — اصلاح آبشار CSS و قابلیت اعتماد

## تغییرات انجام‌شده
- نسخه از `6.3.0` به `6.3.1` ارتقا یافت.
- اعلان‌های `!important` از منبع `css/status-declutter-v62.css` حذف شد تا اولویت‌بندی CSS قابل پیش‌بینی‌تر باشد و با ممیزی امنیتی پروژه سازگار شود.
- فایل CSS نهایی `css/system.css` دوباره از روی ۳۷ فایل منبع ساخته شد.
- Service Worker دوباره ساخته شد و فهرست پیش‌بارگذاری آن ۱۰۴ منبع هم‌مبدأ را شامل می‌شود.
- فراداده نسخه در فایل‌های پروژه با `VERSION` همگام شد.

## نتیجه آزمایش‌ها
دستور `npm test` با موفقیت کامل شد:
- بررسی دود/واحد: ۱۹۱ بررسی موفق و ۲۲ فایل JSON معتبر.
- بررسی ذخیره‌سازی: ۲۰ بررسی موفق.
- بررسی snapshot خودکار: ۵ بررسی موفق.
- ممیزی امنیت و ساخت: ۵۷ بررسی موفق.
- بررسی رجیستری تم‌ها: ۹ تم شناسایی شد.
- باندل CSS: ۳۷ منبع؛ هیچ `!important` در باندل نهایی باقی نماند.
- Service Worker: ۱۰۴ منبع پیش‌بارگذاری‌شونده؛ همه مسیرهای فهرست‌شده در ممیزی معتبر بودند.

## محدودیت آزمایش
آزمایش مرورگر Playwright اجرا نشد؛ فرمان موجود `npm run test:e2e` با خطای `unknown command 'test'` متوقف شد. بنابراین این تحویل را نباید به‌عنوان تأیید کامل آزمون‌های تعاملی مرورگر یا دستگاه واقعی موبایل تلقی کرد. برای آن مرحله باید نصب/اجرای صحیح Playwright و مرورگرهای مربوطه فراهم شود.

## یادداشت
این ارتقا عمداً محدود و کم‌ریسک نگه داشته شد: تغییرات بر رفع شکست ممیزی و همگام‌سازی نسخه متمرکزند و قابلیت‌های اصلی برنامه یا داده‌های ذخیره‌شده کاربر حذف نشده‌اند.
