# گزارش ارتقای My Profile — نسخه 8.4.2

## تغییرات
- افزودن «ستاره شمالی / North Star» برای تعریف مأموریت شخصی و «تمرکز فعلی» برای اولویت‌های دوره جاری.
- افزودن بخش شواهد و نقاط عطف برای ثبت نتایج واقعی، و بخش مرزها/فرض‌نکن‌ها برای ثبت محدودیت‌های شخصی.
- داشبورد تکمیل پروفایل با درصد تکمیل، شمار فیلدهای پرشده و زمان آخرین ذخیره.
- ذخیره خودکار با تأخیر کوتاه، نشانگر تغییرات ذخیره‌نشده و شمارش نویسه‌ها.
- نسخه‌بندی ساختار داده و سازگاری رو به عقب با پروفایل‌های قبلی.
- ورود/خروجی JSON، حذف با تأیید، پیام‌های خطای روشن و توضیح مدل حافظه چهارلایه.
- بهبود ظاهر کارت‌ها، تمرکز صفحه‌کلید و چیدمان موبایل.

## حریم خصوصی و محدوده قابلیت
پروفایل همچنان فقط در localStorage همین مرورگر ذخیره می‌شود و این ماژول اطلاعات را برای سرویس AI ارسال نمی‌کند. «AI Memory» در این نسخه ساختار ثبت و مدیریت اطلاعات است، نه اتصال زنده به مدل هوش مصنوعی.

## اعتبارسنجی
- بررسی نحو JavaScript با `node --check`.
- ساخت CSS و service worker.
- آزمون‌های ایستا و رگرسیون موجود پروژه.
- آزمون اختصاصی Profile Forge.
- آزمون مرورگر واقعی/تصویری Playwright در این محیط اجرا نشده است.
