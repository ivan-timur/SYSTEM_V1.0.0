# گزارش ارتقای SYSTEM v7.3.0 — مرور هفتگی هوشمند

## هدف
افزودن یک مرور هفت‌روزهٔ شفاف به نقشهٔ راه تا کاربر بتواند تعداد گام‌های تازه، گام‌های تکمیل‌شده و کارهای عقب‌افتادهٔ فعلی را یکجا ببیند.

## تغییرات
- افزودن API جدید `weeklyReview()` در `js/core/smart-roadmap.js`.
- محاسبهٔ گام‌های ایجادشده در ۷ روز گذشته با استفاده از `createdAt`.
- محاسبهٔ گام‌های تکمیل‌شده در ۷ روز گذشته با استفاده از `completedAt`.
- شمارش گام‌های باز با مهلت گذشته.
- توزیع تکمیل‌ها بر اساس شاخهٔ مهارت و شناسایی شاخهٔ دارای بیشترین تکمیل در بازه.
- افزودن کارت مرور هفتگی دو‌زبانه و واکنش‌گرا در نقشهٔ راه.
- افزودن پنج بررسی خودکار تازه.
- همگام‌سازی نسخهٔ برنامه، manifest، ماژول نسخه و Service Worker با 7.3.0.

## اصول ایمنی داده
- مرور هفتگی فقط داده‌های موجود را می‌خواند و چیزی را تغییر نمی‌دهد.
- این گزارش، تاریخچهٔ حذف‌شده یا snapshot تاریخی را بازسازی نمی‌کند.
- به‌روزرسانی هیچ XP، سکه یا رتبه‌ای نمی‌دهد.
- ساختار کلید ذخیره‌سازی نقشهٔ راه تغییر نکرده است.

## محدودیت
این شاخص‌ها بر اساس timestampهای موجود در مرورگر هستند؛ پاک‌کردن داده‌ها یا حذف یک گام، تاریخچهٔ کامل و دائمی باقی نمی‌گذارد. برای گزارش تاریخی قابل‌اعتمادتر در چند دستگاه، به لایهٔ ذخیره‌سازی/پشتیبان‌گیری جداگانه نیاز است.
