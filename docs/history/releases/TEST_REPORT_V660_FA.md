# گزارش ارتقای SYSTEM v6.6.0

## قابلیت جدید
ردیاب ارزیابی مهارت‌ها در Status → ⋯ More → Mastery Tracker اضافه شد. کاربر می‌تواند تمرین، آزمون یا پروژه را با نمره ۰ تا ۱۰۰، یادداشت و نشانگر شواهد ثبت کند.

## معیار آمادگی
برای نمایش «نامزد آمادگی»، دست‌کم دو ارزیابی، میانگین حداقل ۸۰٪ در سه ارزیابی اخیر و حداقل یک آزمون/پروژه دارای شواهد لازم است. این شاخص خوداظهاری است و تأیید مستقل مهارت نیست. هیچ XP، سکه یا رتبه‌ای اعطا نمی‌شود.

## سازگاری و ایمنی
- کلید ذخیره‌سازی جدید: `system_v2_skill_assessments`
- سقف تاریخچه: ۳۰۰ ارزیابی
- اعتبارسنجی نوع مهارت، نوع ارزیابی و بازه نمره
- در صورت شکست ذخیره‌سازی، تغییر حافظه برگردانده می‌شود
- خروجی JSON و چیدمان واکنش‌گرا
- تم‌ها و کلیدهای ذخیره‌سازی پیشین حفظ شده‌اند

## وضعیت آزمون
آزمون‌های ایستا، ذخیره‌سازی، ممیزی امنیت و آزمون اختصاصی Mastery اجرا می‌شوند. آزمون مرورگر Playwright جداگانه است و در صورت نبود وابستگی/مرورگر نصب‌شده ممکن است اجرا نشود؛ این گزارش ادعای تأیید کامل رابط تعاملی را ندارد.
