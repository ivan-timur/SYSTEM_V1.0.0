# گزارش ارتقای SYSTEM v9.1.0

**نام نسخه:** Progression Math Module & Browser CI  
**تاریخ:** ۱۵ اکتوبر ۲۰۲۶  
**نسخهٔ پایه:** SYSTEM v9.0.0  
**وضعیت:** آزمون‌های ایستا و بررسی سلامت موفق؛ آزمون واقعی مرورگر در محیط فعلی هنوز اجرا/تأیید نشده است.

## خلاصهٔ اجرایی

این مرحله روی دو مسئلهٔ باقی‌مانده از نسخهٔ 9.0.0 تمرکز دارد: وابستگی محاسبات XP/Rank به کنترل‌گر بزرگ قدیمی و نبود مسیر خودکار قابل‌اتکا برای اجرای آزمون‌های واقعی مرورگر.

### ۱. جداسازی منطق ریاضی پیشرفت

فایل جدید `js/core/progression-math.js` منبع مشترک محاسبهٔ موارد زیر است:

- XP موردنیاز برای Level بازیکن؛
- XP موردنیاز برای Level هر Stat؛
- XP موردنیاز برای هر Skill؛
- آستانه‌های Rank از E تا S.

کنترل‌گر قدیمی به‌جای تکرار فرمول‌ها از API مشترک `window.SYSTEMProgressionMath` استفاده می‌کند. نام توابع مورد استفادهٔ کد قدیمی حفظ شده تا این مهاجرت تدریجی، فراخوانی‌های موجود را نشکند. ماژول پیش از `app-legacy.js` بارگذاری می‌شود و Service Worker نیز آن را در precache قرار می‌دهد.

### ۲. آزمون اختصاصی منحنی‌های پیشرفت

فایل `tests/progression-math-test.js` رفتار پایه، آستانه‌های Rank، نرمال‌سازی سطح‌های نامعتبر، سقف عددی و یکنواخت‌بودن منحنی‌ها را بررسی می‌کند. آزمون روی ۴۹۹ سطح برای هر یک از سه منحنی XP اجرا می‌شود و ۱٬۵۲۱ بررسی مستقل گزارش می‌کند.

### ۳. افزودن مسیر خودکار برای آزمون واقعی مرورگر

گردش‌کار جدید `.github/workflows/quality.yml` در هر Push، Pull Request و اجرای دستی:

1. وابستگی‌های توسعه را نصب می‌کند؛
2. `npm test` را اجرا می‌کند؛
3. `npm run doctor` را اجرا می‌کند؛
4. Chromium و وابستگی‌های سیستمی Playwright را نصب می‌کند؛
5. `npm run test:e2e` را روی پروژه‌های Chromium دسکتاپ و شبیه‌سازی موبایل Pixel 7 اجرا می‌کند؛
6. در صورت شکست، Trace و Screenshotهای موجود را به‌صورت Artifact نگه می‌دارد.

این تغییر امکان اجرای آزمون‌ها را روی runner استاندارد CI فراهم می‌کند؛ اما تا وقتی پروژه در یک مخزن متصل به این گردش‌کار اجرا نشود، نتیجهٔ اجرای CI وجود ندارد.

## محدودیت‌های صریح

### آزمون مرورگر واقعی

در محیط حاضر، وابستگی محلی `@playwright/test` نصب نیست و Chromium مدیریت‌شده با سیاست سیستمی `URLBlocklist: ["*"]` همهٔ پیمایش‌ها، از جمله سرور آزمایشی محلی، را مسدود می‌کند. تلاش برای اجرای Playwright Python نیز با `ERR_BLOCKED_BY_ADMINISTRATOR` هنگام پیمایش به آدرس localhost روبه‌رو شد. سیاست مدیریت‌شدهٔ محیط تغییر داده نشده و دور زده نشده است.

گردش‌کار CI اضافه شده، اما آزمون E2E را نباید تا زمان اجرای موفق آن در یک runner معمولی، تأییدشده فرض کرد. برای اجرای محلی روی دستگاه توسعه:

```bash
npm install
npm test
npm run doctor
npx playwright install chromium
npm run test:e2e
```

### معماری کنترل‌گر قدیمی

این انتشار یک گام امن در مسیر ماژولارسازی است، نه پایان آن. `js/app-legacy.js` هنوز بخش بزرگی از رابط و منطق برنامه را در خود دارد. گام‌های بعدی باید با استخراج تدریجی یک قابلیت، آزمون رگرسیون و بررسی مرورگر انجام شوند؛ بازنویسی یک‌باره توصیه نمی‌شود.

### قفل وابستگی‌ها

در این محیط دسترسی نصب npm به پایان نرسید، بنابراین `package-lock.json` تولید نشده است. گردش‌کار CI از `npm install` استفاده می‌کند؛ برای نصب‌های کاملاً تکرارپذیر، تولید و ثبت lockfile در یک محیط دارای دسترسی به npm registry هنوز لازم است.
