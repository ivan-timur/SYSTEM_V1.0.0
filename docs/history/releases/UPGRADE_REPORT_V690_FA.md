# گزارش ارتقای SYSTEM v6.9.0 — هوشمندی مهلت‌ها

## هدف
این نسخه ادامهٔ نسخهٔ 6.8.0 است و تمرکز آن روی اولویت‌بندی عملی نقشهٔ راه است؛ نه بازنویسی معماری اصلی یا تغییر سیستم پاداش.

## تغییرات
- گام‌های عقب‌افتادهٔ تکمیل‌نشده اکنون قبل از کارهای عادی مرتب می‌شوند.
- گام‌هایی که مهلت‌شان امروز است، بعد از گام‌های عقب‌افتاده و پیش از کارهای عادی قرار می‌گیرند.
- در API خلاصهٔ نقشهٔ راه، شاخص‌های `dueToday`، `dueSoon` و `nextDeadline` افزوده شدند.
- کارت‌های خلاصهٔ نقشهٔ راه، شاخص «مهلت تا ۷ روز / Due in 7 days» را در رابط فارسی و انگلیسی نمایش می‌دهند.
- کلیدهای ذخیره‌سازی قبلی حفظ شده‌اند؛ هیچ XP یا سکه‌ای از نقشهٔ راه صادر نمی‌شود.

## تضمین‌ها و محدودیت‌ها
- داده‌های قبلی و فرمت پشتیبان نقشهٔ راه تغییر نکرده‌اند.
- `dueSoon` کارهای باز با مهلت از امروز تا هفت روز آینده را شامل می‌شود؛ کارهای عقب‌افتاده در شمارش جداگانهٔ `overdue` هستند.
- این ارتقا به‌تنهایی اجرای آزمون تعاملی واقعی در مرورگر را اثبات نمی‌کند.
