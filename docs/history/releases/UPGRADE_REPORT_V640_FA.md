# گزارش ارتقای SYSTEM v6.4.0 — دفتر فعالیت و مرور پیشرفت

## قابلیت جدید
- در صفحه Status و منوی ⋯، ابزار **Activity Ledger / دفتر فعالیت** اضافه شد.
- رویدادهای ثبت‌شدهٔ موجود SYSTEM را با عنوان، تاریخ، نوع رویداد، شاخهٔ مهارت، XP و سکه نمایش می‌دهد.
- خلاصهٔ ۷ روز اخیر شامل تعداد فعالیت‌ها، مجموع XP و مجموع سکه‌ها محاسبه می‌شود.
- امکان دریافت تاریخچهٔ ثبت‌شده در قالب JSON برای نگهداری یا بررسی بیرون از برنامه اضافه شد.
- نمایش واکنش‌گرا برای صفحه‌های کوچک و متن‌های فارسی/انگلیسی در رابط ابزار در نظر گرفته شد.
- API فقط‌خواندنی `window.SYSTEMProgressLedger` برای فهرست رویدادها، خلاصهٔ بازه و خروجی JSON اضافه شد.
- ساختار و کلیدهای ذخیره‌سازی تاریخچهٔ موجود تغییر نکردند؛ تاریخچه همچنان محلی است و تا ۳۰۰ رویداد اخیر را نگه می‌دارد.

## آزمایش‌های اجراشده
دستور `npm test` با موفقیت اجرا شد:
- ساخت CSS و Service Worker موفق؛ ۳۷ منبع CSS و ۱۰۴ منبع precache.
- آزمون دود/واحد: **۲۰۰ بررسی موفق** و ۲۲ فایل JSON معتبر.
- آزمون ذخیره‌سازی: **۲۰ بررسی موفق**.
- آزمون snapshot خودکار: **۵ بررسی موفق**.
- ممیزی امنیت و ساخت: **۵۷ بررسی موفق**.
- آزمون‌های تازهٔ دفتر فعالیت: ثبت رویداد، ترتیب جدیدترین فعالیت، خلاصهٔ XP/سکه و ساختار خروجی JSON.
- رجیستری ۹ تم بررسی شد؛ تم‌های قبلی حذف نشدند.

## محدودیت آزمایش
آزمون مرورگر Playwright اجرا نشد؛ `npm run test:e2e` با خطای `unknown command 'test'` متوقف شد. در نتیجه، دانلود واقعی JSON، تعاملات UI و نمایش در مرورگر/موبایل در این محیط به‌صورت end-to-end تأیید نشده‌اند.

## نکتهٔ حریم خصوصی و دقت
دفتر فقط رویدادهایی را نشان می‌دهد که نسخهٔ فعلی SYSTEM از قبل ثبت کرده است؛ این قابلیت گذشته را به‌طور مصنوعی بازسازی نمی‌کند. داده‌ها در ذخیره‌سازی محلی مرورگر می‌مانند و زمان رویداد از ساعت دستگاه گرفته می‌شود؛ بنابراین این دفتر به‌تنهایی مدرک ضدتقلب یا همگام‌سازی ابری نیست.
