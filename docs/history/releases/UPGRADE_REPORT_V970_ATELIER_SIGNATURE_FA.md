# گزارش ارتقای SYSTEM v9.7.0 — Atelier Signature

## هدف
این نسخه یک لایهٔ بصری افزایشی روی تم‌های نسخهٔ 9.6.0 اعمال می‌کند؛ هدف، پرداخت تخصصی‌تر سطوح، تایپوگرافی، حالت‌های تعاملی و دسترس‌پذیری است، نه تغییر دوبارهٔ ساختار یا منطق برنامه.

## تغییرات
- افزودن لایهٔ CSS مستقل `css/theme-atelier-v97.css` به خط ساخت رسمی CSS.
- ارتقای ظرافت پنل‌ها با لبهٔ نورانی محدود، عمق سایه و حالت Hover کنترل‌شده.
- بهبود سلسله‌مراتب عنوان‌ها و خوانایی توضیحات بدون وابستگی به فونت خارجی.
- پرداخت نوارهای پیشرفت با عمق داخلی و بازتاب نور کم‌شدت؛ مقادیر XP و پیشرفت تغییر نمی‌کنند.
- افزودن حلقهٔ فوکوس واضح برای کار با صفحه‌کلید و کنترل‌های قابل تعامل.
- محدودکردن حرکت برجسته به دستگاه‌های دسکتاپی دارای Hover؛ در موبایل حرکت کمتر و در تنظیم کاهش حرکت، انیمیشن‌ها محدود می‌شوند.
- حفظ شناسه‌ها و انتخاب‌پذیری هر ۱۱ تم قبلی: cosmic، aether، couture، royal، aurora، abyss، ice، crimson، emerald، solar و sakura.
- عدم تغییر منطق XP، سکه، رتبه، مأموریت، داده‌های ذخیره‌شده یا موتور هوش.

## اعتبارسنجی
آزمون‌های پروژه از طریق `npm test` اجرا شده‌اند. این آزمون‌ها ساخت CSS و Service Worker، آزمون‌های ایستا و رگرسیون پروژه و آزمون جدید Atelier Signature را شامل می‌شوند. آزمون مرورگر واقعی و ساخت APK جداگانه محسوب می‌شوند و در این گزارش به‌عنوان انجام‌شده ادعا نمی‌شوند.
