# SYSTEM 7.8.0 — گزارش ارتقای حداکثری

## تغییرات این نسخه
- افزودن لایه‌ی یکپارچه‌سازی بصری Apex Finish برای هماهنگ‌سازی کارت‌ها، دکمه‌ها، فیلدهای ورودی، پنجره‌ها و حالت‌های تعاملی.
- بهبود نمایش در موبایل: جلوگیری از بیرون‌زدگی متن و کارت‌ها، حداقل اندازه‌ی مناسب‌تر کنترل‌های لمسی و اندازه‌ی ورودی مناسب برای جلوگیری از زوم خودکار مرورگرهای موبایل.
- بهبود دسترس‌پذیری: نشانگر واضح فوکوس صفحه‌کلید، رفتار تعاملی hover/pressed و پشتیبانی از ترجیح کاهش حرکت.
- حفظ تم Obsidian Couture به‌عنوان گزینه‌ای اختیاری و نگه‌داشتن تم‌های قبلی.
- حفظ منطق XP، لول، مهارت‌ها، کوئست‌ها، سکه‌ها، Rewards و ساختار ذخیره‌سازی؛ این نسخه مهاجرت داده انجام نمی‌دهد.
- بازسازی CSS نهایی و Service Worker با نسخه‌ی 7.8.0 و 118 منبع کش آفلاین.

## محدودیت آزمون
آزمون مرورگر Playwright اجرا نشد؛ فرمان نصب‌شده‌ی Playwright در محیط پاسخ‌گو دستور `test` را نمی‌شناسد. بنابراین آزمون‌های خودکار منطقی/ساخت موفق‌اند، اما این گزارش ادعای تأیید کامل E2E در مرورگر واقعی یا گوشی را نمی‌کند.

## اجرای پروژه
برای اجرای نسخه‌ی محلی، فایل ZIP را استخراج کنید و `index.html` را از طریق یک وب‌سرور محلی باز کنید. اگر تغییرات قبلی از Service Worker کش شده‌اند، یک بار صفحه را تازه‌سازی سخت کنید یا کش سایت را پاک کنید.
