# گزارش ارتقای SYSTEM v6.7.0 — نقشه راه هوشمند

## قابلیت‌های اضافه‌شده
- ابزار Smart Roadmap در مسیر Status → ⋯ More اضافه شد.
- امکان ساخت گام با عنوان، شاخه مهارت، اولویت، مهلت اختیاری و یادداشت.
- تغییر وضعیت بین انجام‌نشده، در حال انجام و تکمیل‌شده؛ امکان بازگشایی یا حذف گام.
- خلاصه تعداد گام‌ها، گام‌های تکمیل‌شده، درصد پیشرفت و گام‌های عقب‌افتاده.
- مرتب‌سازی بر اساس وضعیت، اولویت و مهلت؛ خروجی JSON برای پشتیبان‌گیری.
- ذخیره‌سازی محلی با اعتبارسنجی ورودی، سقف ۲۰۰ گام و بازگردانی حافظه در صورت شکست ذخیره‌سازی.
- متن یادداشت هنگام نمایش escape می‌شود؛ گام‌های نقشه راه XP، سکه یا رتبه اعطا نمی‌کنند.

## آزمون‌های اجراشده
- `npm test`: موفق.
- آزمون‌های smoke/unit: ۲۱۹ بررسی؛ ۲۲ فایل JSON معتبر.
- آزمون‌های ذخیره‌سازی: ۲۰ بررسی.
- آزمون snapshot خودکار: ۵ بررسی.
- ممیزی امنیت/ساخت: ۵۷ بررسی؛ ۱۱۰ منبع در precache.
- آزمون Mastery Tracker: ۱۷ بررسی.
- آزمون Smart Roadmap: ۲۴ بررسی.
- ساخت CSS: ۴۰ فایل منبع؛ صفر مورد `!important` در CSS تولیدشده.
- Service Worker برای نسخه 6.7.0 با ۱۱۰ منبع بازسازی شد.

## محدودیت آزمون
آزمون تعاملی Playwright اجرا نشد؛ محیط فعلی دستور Playwright قابل استفاده ندارد (`unknown command 'test'`). تلاش برای اجرای مرورگر headless نیز در محدودیت زمانی محیط پایان نیافت. بنابراین تست خودکار مدل، ساخت، ذخیره‌سازی و ممیزی انجام شده، اما تأیید کامل تعاملات واقعی مرورگر/موبایل گزارش نمی‌شود.

## سازگاری
قابلیت جدید از کلید ذخیره‌سازی جداگانه `system_v2_smart_roadmap` استفاده می‌کند و به داده‌ها، تم‌ها و کلیدهای ذخیره‌سازی قبلی دست نمی‌زند.
