# گزارش ارتقای SYSTEM v6.5.0 — مرور مهارت مبتنی بر شواهد

## قابلیت افزوده‌شده
- مسیر دسترسی: صفحه Status ← منوی سه‌نقطه (⋯) ← Skill Review.
- کاربر می‌تواند برای هر یک از شش شاخه مهارتی، میزان اطمینان خود را از ۱ تا ۵ ثبت کند.
- امکان افزودن یادداشت کوتاه و علامت‌گذاری وجود شواهد عملی مانند تمرین، آزمون یا پروژه فراهم شده است.
- مرورهای اخیر، میانگین خودارزیابی هر شاخه و پیشنهاد تمرکز بر اساس پایین‌ترین میانگین نمایش داده می‌شود.
- خروجی JSON برای انتقال یا نگهداری تاریخچه مرورها وجود دارد.
- تاریخچه در مرورگر محلی ذخیره و به حداکثر ۳۰۰ رکورد محدود می‌شود.

## مرزهای صداقت محصول
- مرور مهارت XP، سکه، رتبه یا وضعیت تسلط اعطا نمی‌کند.
- امتیازها خوداظهاری هستند؛ علامت شواهد نیز توسط خود کاربر انتخاب می‌شود و تأیید مستقل محسوب نمی‌شود.
- اطلاعات بین دستگاه‌ها همگام نمی‌شود و با پاک‌کردن داده‌های مرورگر ممکن است از بین برود؛ از خروجی/پشتیبان استفاده کنید.

## سازگاری و بررسی
- `npm run build` موفق شد: نسخه‌ها همگام شدند، CSS از ۳۸ منبع ساخته شد و Service Worker تعداد ۱۰۶ منبع را پیش‌بارگذاری می‌کند.
- `npm run test:static` موفق شد: ۲۱۷ بررسی دود/واحد، ۲۰ بررسی ذخیره‌سازی، ۵ بررسی snapshot خودکار و ۵۷ بررسی ممیزی امنیت/ساخت موفق بودند؛ ۲۲ فایل JSON نیز معتبر بودند.
- `npm run test:e2e` اجرا شد اما محیط موجود فرمان Playwright را با `unknown command 'test'` رد کرد؛ بنابراین آزمون مرورگر واقعی انجام نشده است.
- کلیدهای ذخیره‌سازی موجود، تم‌های فعلی و ساختار ذخیره قبلی تغییر داده نشدند.
- CSS فعال از فایل منبع بازسازی و Service Worker از فهرست دارایی‌های پروژه دوباره تولید شد.
- نتیجه آزمون‌های واقعی در این گزارش پس از اجرای دستورهای ساخت و تست درج می‌شود.
