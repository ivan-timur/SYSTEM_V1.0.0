# گزارش ارتقای My Profile Intelligence — SYSTEM 8.5.0

## تغییرات اصلی
- پل واقعی و رضایت‌محور میان پروفایل و درخواست‌های AI در Groq و Gemini.
- اشتراک‌گذاری پیش‌فرض خاموش است؛ انتخاب دسته‌های زمینه جداگانه و قابل لغو است.
- آزمون اتصال API هرگز اطلاعات پروفایل را همراه خود نمی‌فرستد.
- زمینهٔ ارسالی محدود به فیلدهای انتخاب‌شده و کوتاه‌شده است؛ دسته‌های خالی ارسال نمی‌شوند.
- امکان ساخت خلاصهٔ شخصی کاملاً محلی بدون درخواست شبکه.
- تحلیل پروفایل توسط AI با درخواست صریح کاربر، خروجی ساختاریافته و وضعیت پیشنهادی.
- امکان علامت‌گذاری تحلیل به‌عنوان مفید/بازبینی‌شده یا نادقیق.
- تنظیمات رضایت و تحلیل‌ها در خروجی JSON ذخیره می‌شوند؛ واردکردن نسخه‌های قدیمی هرگز رضایت اشتراک‌گذاری را روشن نمی‌کند.
- هیچ تحلیل پروفایلی به‌طور خودکار XP، Coins، Level، Rank، مهارت یا مأموریت را تغییر نمی‌دهد.

## حدود و حریم خصوصی
پروفایل و تحلیل‌های ذخیره‌شده روی همین مرورگر می‌مانند، تا زمانی که کاربر خودش خروجی بگیرد یا گزینهٔ اشتراک‌گذاری را برای درخواست‌های AI روشن کند. وقتی رضایت فعال است، فقط فیلدهای انتخاب‌شده به ارائه‌دهندهٔ متصل ارسال می‌شوند. متن پیام و تاریخچهٔ چت همچنان مطابق رفتار قبلی بخش AI پردازش می‌شوند. ذخیرهٔ کلید API در حافظهٔ تب و معماری local-first تغییر نکرده است.

## آزمایش‌ها
آزمون‌های جدید بررسی می‌کنند که رضایت پیش‌فرض خاموش باشد، زمینه بر اساس فیلدهای انتخاب‌شده ساخته شود، حدود طول رعایت شود، اطلاعات حساس از دسته‌های انتخاب‌نشده نشت نکند، تحلیل‌ها امن رندر شوند و ورودی نسخهٔ قدیمی بدون فعال‌کردن رضایت مهاجرت کند.
