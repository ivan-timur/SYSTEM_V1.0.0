# گزارش ارتقای Android برای SYSTEM v9.3.0

## خروجی این مرحله

- پروژهٔ بومی Android در پوشهٔ `android/` ایجاد شد؛ شناسهٔ برنامه `com.cronus.system` است.
- رابط موجود، CSS، تصاویر و اسکریپت‌ها به‌صورت محلی داخل APK بسته‌بندی می‌شوند؛ برای بازشدن رابط اصلی به وب‌سرور احتیاج نیست.
- از `WebViewAssetLoader` استفاده شده تا ES Modules و سیاست same-origin با نشانی HTTPS محلی سازگار بمانند.
- ذخیره‌سازی فعلی SYSTEM در localStorage پایدار WebView حفظ شده است. این نسخه هنوز مهاجرت داده‌ها به SQLite را انجام نمی‌دهد.
- اعلان روزانهٔ بومی قابل روشن/خاموش‌کردن به تنظیمات Sound & Alerts اضافه شد؛ زمان‌بندی تقریبی است و به اجازهٔ اعلان اندروید وابسته است.
- ورودی فایل برای بازیابی backup و پنجرهٔ بومی ذخیره‌سازی برای خروجی‌های JSON/CSV پشتیبانی می‌شود.
- لینک‌های بیرونی به مرورگر دستگاه فرستاده می‌شوند؛ WebView اجازهٔ محتوای mixed-content را نمی‌دهد و دسترسی مستقیم file:// غیرفعال است.
- گردش‌کار دستی GitHub Actions برای ساخت Debug APK و راهنمای فارسی ایجاد شد.
- دو مشکل پیشین آزمون/سبک هم اصلاح شد: آزمون تشخیص تم‌های اختصاصی Aether/Couture و overrideهای reduced-motion بدون `!important`.

## حفظ ویژگی‌های فعلی

صفحه‌های Status، Quest، Rewards، AI و Settings و منطق موجود Goals، Smart Roadmap، Skill Curriculum/Mastery، XP/Level و پشتیبان‌گیری در بستهٔ وب نگه داشته شده‌اند. یادآور اندروید فقط یک یادآور روزانهٔ عمومی است و در پس‌زمینه مأموریت‌ها را تحلیل یا از هوش مصنوعی آنلاین پرس‌وجو نمی‌کند. قابلیت‌های AI که به API وصل‌اند همچنان به اینترنت نیاز دارند.

## اعتبارسنجی انجام‌شده

- `npm test`: موفق؛ تمام مجموعه‌آزمون‌های ایستا پیکربندی‌شده اجرا شدند.
- `npm run doctor`: موفق؛ ساختار و فایل‌های runtime معتبر تشخیص داده شدند.
- `node --check` برای `js/app.js`، `js/experience.js`، `js/modules/android-native.js` و `scripts/sync-android-assets.js`: موفق.
- XMLهای Android: قابل‌خواندن و parse شدند.
- `npm run prepare:android`: موفق؛ ۱۱۵ فایل وب با حجم حدود ۵٫۶۵ MiB بسته‌بندی شد.

## محدودیت تأیید

در محیط ساخت فعلی Android SDK و Gradle موجود نیستند و میزبان نتوانست به سرورهای دانلود Google/Gradle وصل شود. ازاین‌رو فایل APK از این محیط کامپایل نشده و اجرای واقعی روی دستگاه نیز هنوز تأیید نشده است. برای تولید APK، از Android Studio با Gradle/SDK نصب‌شده یا گردش‌کار `.github/workflows/build-android.yml` استفاده کن.
