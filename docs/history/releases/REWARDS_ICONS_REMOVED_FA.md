# گزارش اصلاح — حذف آیکون‌های جوایز

در این نسخه، آیکون‌ها و شکلک‌های تزئینی از کارت‌های جوایز و پنل جزئیات جایزه حذف شدند.

- آیکون از کارت‌های ثابت جوایز و پنل جایزهٔ انتخاب‌شده حذف شد.
- ساخت کارت‌های جوایز پویا دیگر آیکون ایجاد نمی‌کند.
- نگاشت شکلک‌های پاداش و نمادهای تزئینی مسیرهای پیشرفت حذف شد.
- منطق دریافت جایزه، XP، سکه‌ها، پیشرفت، فیلترها و شناسه‌های ذخیره‌شده تغییر نکرد.
- قواعد CSS قدیمی `!important` پاک شدند؛ فرایند ساخت پروژه از قبل این نشانگرها را از فایل runtime حذف می‌کرد.

## بررسی‌ها

همهٔ ۱۳ مجموعه‌آزمون اجراشده موفق شدند؛ شامل آزمون‌های رابط، ذخیره‌سازی، امنیت، مهارت‌ها، مسیر پیشرفت، Rewards و جوایز روزانه.
