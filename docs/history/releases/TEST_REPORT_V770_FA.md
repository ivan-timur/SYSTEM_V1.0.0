# گزارش آزمون نسخهٔ 7.7.0 — Obsidian Couture

## ساخت و آزمون‌های خودکار
- Build و همگام‌سازی نسخه: موفق؛ نسخهٔ canonical برابر 7.7.0 است.
- Bundler CSS: موفق؛ 45 منبع یکتا در stylesheet نهایی؛ صفر `!important`.
- Service Worker: موفق؛ 117 ورودی precache و فایل‌های تم جدید در cache فهرست شده‌اند.
- Smoke/Unit و اعتبارسنجی JSON: 232 بررسی موفق.
- Storage: 22 بررسی موفق.
- Auto-snapshot: 5 بررسی موفق.
- Security/Build audit: 57 بررسی موفق.
- Skill Mastery: 17 بررسی موفق.
- Skill progression: 1,324 بررسی موفق روی 583 گرهٔ برنامهٔ درسی.
- Smart Roadmap: 83 بررسی موفق.
- Rewards Ascension: 39 بررسی موفق.
- Obsidian Couture: بررسی‌های اختصاصی تم، ماندگاری تنظیم، حفظ تم‌های قبلی، CSS واکنش‌گرا، کاهش حرکت و cache آفلاین نیز اجرا شده‌اند.

## ممیزی بصری
برای ممیزی بصری، HTML واقعی پروژه و CSS ساخته‌شده در مرورگر Chromium به‌صورت رندر ایستا (بدون اجرای ماژول‌های JavaScript) در اندازهٔ دسکتاپ 1440px و موبایل 390px نمایش داده شدند. عرض سند در هر دو اندازه برابر عرض viewport ماند؛ اسکرول افقی ناخواسته مشاهده نشد. بخش Rewards از نظر کارت‌ها، پنل منتخب، مسیر Daily Reward و دکمه‌ها بازبینی شد.

## محدودیت آزمون تعاملی
آزمون end-to-end واقعی از طریق ناوبری مرورگر در این محیط اجرا نشد؛ مدیریت مرورگر آدرس‌های برنامه را با خطای `ERR_BLOCKED_BY_ADMINISTRATOR` مسدود کرد. بنابراین آزمون تعاملی را موفق اعلام نمی‌کنیم. در عوض Build و تمام آزمون‌های منطقی/ایستای بالا اجرا شدند و موفق بودند.
