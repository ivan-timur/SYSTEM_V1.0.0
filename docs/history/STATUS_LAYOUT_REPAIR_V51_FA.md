# گزارش اصلاح چیدمان Status — نسخه ۵.۱

## تغییرات اصلی

- ساختار صفحهٔ Status دوباره تنظیم شد تا عنوان Level در مرکز بماند و کارت‌های Level، Rank و XP در یک شبکهٔ هماهنگ قرار بگیرند.
- در نمایشگر بزرگ، Level، Rank و XP در یک ردیف‌اند؛ در تبلت و موبایل، Level و Rank کنار هم و XP در ردیف بعدی نمایش داده می‌شوند.
- شش کارت Stats در نمایشگرهای بزرگ سه‌ستونه، در موبایل معمولی دو‌ستونه و در صفحه‌های بسیار باریک تک‌ستونه می‌شوند.
- اندازهٔ آیکون‌ها، متن، فاصله‌ها، نوارهای XP و کارت‌ها با عرض دستگاه تنظیم می‌شود؛ متن‌ها از کارت بیرون نمی‌زنند و از فاصله‌های بی‌دلیل جلوگیری شده است.
- اطلاعات رتبه به‌صورت یک گروه منظم کنار تصویر Rank قرار گرفت. کد موجود برای هماهنگ‌سازی رتبه با Level همچنان از همین عناصر پشتیبانی می‌کند.
- چیدمان Status در تبلت اصلاح شد تا فضای خالی ناشی از حاشیهٔ قدیمی نوار کناری باقی نماند.

## یکپارچه‌سازی CSS

- `css/pages/status.css` به مرجع اصلی و یگانهٔ چیدمان و اندازه‌بندی صفحهٔ Status تبدیل شد و در انتهای فهرست stylesheetها بارگذاری می‌شود.
- تعریف‌های متناقض و قدیمیِ مربوط به Status از ۱۷ فایل CSS دیگر حذف شدند؛ استایل‌های غیرمرتبط با Status برای سایر صفحه‌ها حفظ شده‌اند.
- فایل اصلی چیدمان Status دیگر به `!important` نیاز ندارد.

## آزمون‌های انجام‌شده

- CSSها از نظر خطاهای تجزیه بررسی شدند: بدون خطای CSS.
- فایل‌های JavaScript با `node --check` بررسی شدند: بدون خطای نحوی.
- چیدمان در عرض‌های ۳۲۰، ۳۹۰، ۷۶۸ و ۱۳۶۵ پیکسل در مرورگر بررسی شد؛ در این اندازه‌ها سرریز افقی دیده نشد.

یادداشت: آزمون ظاهری با بارگذاری HTML و CSS و دارایی‌های محلی انجام شد؛ رفتارهای تعاملی برنامه به‌طور کامل آزمون انتهابه‌انتها نشده‌اند.
