# فاز ۳۱ — دروازه‌های اعتبارسنجی ذخیره‌سازی و انتشار

## هدف
این فاز یک دروازهٔ قراردادی پیش از آزمون واقعی ایجاد می‌کند. تمرکز بر وجود مسیر آزمون IndexedDB در مرورگر، سناریوهای ماندگاری داده، همگام‌سازی منابع Android و هماهنگی نسخه است. این فاز مهاجرت ذخیره‌سازی را فعال نمی‌کند و فایل‌های اجرایی برنامه را به‌طور خودکار تغییر نمی‌دهد.

## کنترل‌های افزوده‌شده
- آزمون قراردادی مستقل برای اطمینان از وجود دستور `test:browser-idb` و صفحهٔ آزمون مرورگر.
- کنترل وجود سناریوهای بستن و بازکردن پایگاه، تکمیل تکراری و مسیرهای مهاجرت در آزمون IndexedDB.
- بررسی قرارداد همگام‌سازی HTML، Service Worker، manifest، نسخه، منابع وب و خروجی TypeScript به بستهٔ Android.
- بررسی تطابق نسخهٔ مرجع `VERSION` با `manifest.webmanifest` و `versionName` پیکربندی Android.
- اتصال آزمون فاز ۳۱ به `npm run test:static`.

## فایل آزمون
`tests/phase31-storage-release-gates-test.js`

## محدودیت اعتبارسنجی
آزمون فاز ۳۱، قراردادهای منبع را بررسی می‌کند. این نتیجه به‌تنهایی اجرای `npm test` کامل، آزمون IndexedDB در مرورگر واقعی، ساخت APK، نصب روی دستگاه یا به‌روزرسانی بدون ازدست‌رفتن اطلاعات را اثبات نمی‌کند. این مراحل باید در محیط دارای وابستگی‌ها، مرورگر و Android SDK اجرا شوند.

## معیار پیش از cutover
1. اجرای موفق `npm test` در محیط دارای وابستگی‌های نصب‌شده.
2. اجرای موفق `npm run test:browser-idb` در Chromium/Playwright.
3. اتصال کامل مسیرهای زندهٔ رابط به فرمان‌های اتمی، پس از ممیزی و آزمون.
4. پشتیبان‌گیری و تأیید صریح پیش از هر مهاجرت داده.
5. ساخت APK، نصب و آزمون به‌روزرسانی روی دستگاه واقعی.

تا زمان عبور از این معیارها، `localStorage` مسیر زندهٔ مرجع باقی می‌ماند و مهاجرت خودکار یا dual-write کنترل‌نشده فعال نمی‌شود.
