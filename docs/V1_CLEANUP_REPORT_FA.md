# گزارش پاک‌سازی و سازمان‌دهی SYSTEM v1.0.0

## تغییرات
- نسخهٔ مرجع پروژه به `1.0.0` تغییر کرد؛ فایل `VERSION` مرجع اصلی است.
- نام بسته به `system-v1` تغییر کرد.
- نسخهٔ `package.json`، `manifest.webmanifest`، کدهای نسخه، Service Worker و بستهٔ Android با اسکریپت رسمی همگام‌سازی شدند.
- ۴۰ گزارش تاریخی از ریشه به `docs/releases/history/` منتقل شدند تا پوشهٔ اصلی خواناتر باشد.
- README با نقشهٔ پوشه‌ها و توضیح سیاست نسخه‌گذاری بازآرایی شد.
- فایل‌های اجرایی، داده‌ها، دارایی‌ها، آزمون‌ها و منابع Android حذف نشدند؛ چون حذف بدون شواهد می‌تواند قابلیت‌های پروژه را بشکند.

## ساختار اصلی
`index.html`, `css/`, `js/`, `src/`, `data/`, `assets/`, `tests/`, `scripts/`, `dist/`, `android/`, `docs/`
