# گزارش ارتقای SYSTEM v1.4.0 — جداسازی تجزیه‌گر مأموریت‌های AI

## چه تغییر کرد؟

- منطق خالص تشخیص متن مأموریت، پاک‌سازی قالب Markdown، خواندن فهرست‌های شماره‌دار و نقطه‌ای و تشخیص Stat مرتبط از فایل بزرگ `js/legacy/app-controller.js` بیرون کشیده شد.
- قابلیت‌های مذکور اکنون در `js/features/ai-quest-parser.js` قرار دارند و از رابط محدود و تغییرناپذیر `window.SYSTEMAIQuestParser` استفاده می‌کنند. توابع داخلی به‌صورت متغیر عمومی در پنجره منتشر نمی‌شوند.
- نقطهٔ ورود `js/app.js` این فایل را پیش از کنترلر legacy بارگذاری می‌کند و محل‌های استفاده به API تازه متصل شده‌اند.
- آزمون مستقل برای ورودی خالی، متن چندخطی، توضیحات ادامه‌دار، Markdown، شماره‌های فارسی و عربی، حذف تکرارها، محدودیت طول، تشخیص شش Stat و ترتیب بارگذاری اضافه شد.

## چرا این مرحله انتخاب شد؟

این بخش از کنترلر قدیمی وابستگی به DOM یا وضعیت ذخیره‌سازی ندارد و بنابراین یک مرحلهٔ کم‌خطر برای شروع ماژولارکردن واقعی است. با این حال، اتصال اصلی تکمیل Quest و محاسبهٔ XP هنوز عمداً تغییر نکرده است؛ آن بخش باید در یک مرحلهٔ جدا با آداپتر سازگار و آزمون‌های رگرسیون منتقل شود تا پاداش‌ها دوباره داده نشوند یا ذخیره‌های موجود آسیب نبینند.

## آزمون و محدودیت

- `npm test`: موفق؛ ساخت CSS/Service Worker، ساخت TypeScript، آزمون‌های progression و persistence و seed، و کل آزمون‌های موجود پروژه با موفقیت گذشتند. آزمون جدید تجزیه‌گر اکنون ۳۷ بررسی دارد.
- `npm run prepare:android`: موفق؛ نسخهٔ وب به دارایی‌های Android کپی شد (۱۲۰ فایل، حدود ۵٫۸۶ MiB) و فایل parser در مسیر Android با نسخهٔ وب مقایسه و تأیید شد.
- `npm run doctor`: موفق؛ فایل‌های ضروری و اطلاعات نسخه سازگارند.
- آزمون‌های end-to-end مرورگر اجرا نشدند، چون وابستگی محلی `@playwright/test` نصب نیست؛ Chromium موجود نیز در این محیط حتی برای یک صفحهٔ سادهٔ آزمایشی به‌درستی شروع نشد. بنابراین اجرای واقعی UI در مرورگر تأییدشده تلقی نمی‌شود.
- APK ساخته نشد؛ در این محیط دستور `gradle` و Android SDK تنظیم‌شده موجود نیستند. آماده‌سازی دارایی‌های وب Android انجام شده است، اما این با ساخت APK یکسان نیست.

هشدار غیرمسدودکنندهٔ Node دربارهٔ نوع ماژول خروجی TypeScript نیز در آزمون دیده می‌شود؛ آزمون‌های TypeScript با موفقیت پایان می‌یابند.
