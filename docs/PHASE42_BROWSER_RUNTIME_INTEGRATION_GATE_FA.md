# فاز ۴۲ — دروازهٔ یکپارچگی مرورگر واقعی

## هدف

این فاز تلاش می‌کند آزمون واقعی IndexedDB را با Chromium اجرا کند و در عین حال، محدودیت‌های امنیتی مدیریت‌شدهٔ محیط را دور نزند.

## اجرای انجام‌شده

فرمان اجراشده:

```sh
CHROMIUM_PATH=/usr/bin/chromium SYSTEM_BROWSER_TEST_VERBOSE=1 npm run test:browser-idb
```

ساخت TypeScript موفق شد و runner توانست سرور محلی و Chromium را راه‌اندازی کند. اما Chromium در زمان بازکردن صفحهٔ آزمون خطای `ERR_BLOCKED_BY_ADMINISTRATOR` برگرداند. محیط شامل سیاست‌های مدیریت‌شدهٔ `URLBlocklist: ["*"]` بود.

**نتیجهٔ واقعی: آزمون IndexedDB در مرورگر مسدود شد و هیچ نتیجهٔ PASS/FAIL از خود سناریوهای IndexedDB تولید نشد.** این نتیجه نباید به‌عنوان موفقیت آزمون مرورگر گزارش شود.

## رفتار ایمنی

- سیاست مرورگر تغییر داده نشد.
- محدودیت URL دور زده نشد.
- مهاجرت خودکار و dual-write فعال نشد.
- وضعیت ذخیره‌سازی قدیمی تغییر نکرد.
- آزمون قراردادی فاز ۴۲ افزوده شد تا runner، سناریوهای مرورگر و گزارش صریح مسدودشدن در مجموعهٔ static باقی بمانند.

## اجرای لازم در محیط مجاز

در CI یا رایانه‌ای که سیاست مرورگر اجازهٔ دسترسی به `localhost` را می‌دهد، اجرا شود:

```sh
npm run test:browser-idb
```

سپس خروجی سناریوهای IndexedDB باید بررسی شود. پس از آن هنوز اجرای مجموعهٔ کامل آزمون‌ها، ساخت APK واقعی و آزمون دستگاه Android لازم است.

## وضعیت دروازه

- ساخت TypeScript: موفق
- راه‌اندازی runner و Chromium: موفق
- بازکردن صفحهٔ localhost: مسدود توسط سیاست محیط
- آزمون واقعی IndexedDB: **در انتظار اجرای مجدد در محیط مجاز**
- APK و دستگاه واقعی: **تأیید نشده‌اند**
