# فاز ۱۵ — اعتبارسنجی دوام ذخیره‌سازی

## هدف

این فاز یک آزمون واقعی مرورگر به مجموعهٔ IndexedDB اضافه می‌کند تا بررسی شود رکوردی که تراکنش آن با موفقیت commit شده، پس از بستن اتصال پایگاه داده و بازکردن دوبارهٔ آن همچنان قابل‌خواندن است.

## پوشش آزمون

- نوشتن رکورد آزمایشی جداشده در `app_state` و انتظار برای `transaction complete`.
- بستن اتصال نویسنده و بازکردن دوبارهٔ پایگاه داده.
- بررسی باقی‌ماندن مقادیر آزمایشی XP، Level، Rank و شناسهٔ مأموریت.
- حذف فقط همان رکورد آزمایشی پس از تأیید، برای جلوگیری از آلودگی سایر آزمون‌ها.
- آزمون قراردادی ایستا برای اطمینان از اتصال آزمون مرورگر به فرمان `test:browser-idb`.
- حفظ مهاجرت صریح، تشخیص سلامت فقط‌خواندنی و جلوگیری از پاک‌کردن خودکار داده‌ها.

## اجرای آزمون‌ها

در محیط دارای Node.js 20 یا بالاتر، وابستگی‌های پروژه و مرورگر Chromium نصب‌شده: `npm run test:browser-idb`

برای بررسی‌های ایستا: `npm run test:static`

## محدودیت مهم

این آزمون دوام IndexedDB را در مرورگر واقعی بررسی می‌کند؛ به‌تنهایی خاموشی ناگهانی دستگاه، پاک‌شدن داده توسط سیستم‌عامل، کمبود فضای دیسک، حفظ داده در به‌روزرسانی APK یا عملکرد WebView روی گوشی واقعی را اثبات نمی‌کند. این موارد باید جداگانه آزمایش شوند. در این فاز منبع اصلی ذخیره‌سازی رابط کاربری تغییر نکرده و مهاجرت خودکار یا نوشتن دوگانه فعال نشده است.
