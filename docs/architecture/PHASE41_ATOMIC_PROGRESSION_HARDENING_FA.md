# فاز ۴۱ — تقویت اتمی چرخهٔ پیشرفت

## هدف
این فاز تضمین‌های قابل‌بررسی در سطح کد را پیرامون تکمیل مأموریت، XP، مهارت، آمار، تاریخچه و پاداش تقویت می‌کند؛ بدون تغییر دادن مسیر ذخیره‌سازی فعال کاربر.

## قراردادهای محافظت‌شده
1. رکوردهای وابستهٔ پیشرفت باید در یک تراکنش `readwrite` مشترک نوشته شوند.
2. نتیجهٔ فرمان تنها پس از تکمیل تراکنش موفق اعلام می‌شود؛ خطای نوشتن باید مسیر لغو تراکنش را فعال کند.
3. وضعیت‌های ناسازگار میان بازیکن، مأموریت، رویداد XP و رویداد بازیکن باید به‌عنوان تعارض متوقف شوند، نه اینکه دوباره پاداش بدهند.
4. بازپخش تکمیل قبلی باید با مقدار XP واقعاً اعطاشده (`awardedXP`) سازگار باشد.
5. شناسهٔ رویداد تاریخچه و شناسهٔ دفتر XP پاداش روزانه باید برای جلوگیری از ثبت تکراری بررسی شوند.
6. مقدار پاداش Daily Quest از رکورد ذخیره‌شدهٔ مأموریت می‌آید، نه از اعداد دلخواه رابط کاربری.
7. `localStorage` تا زمان تأیید مهاجرت صریح، مرجع مسیر قدیمی باقی می‌ماند؛ مهاجرت خودکار و dual-write فعال نمی‌شوند.

## اجرا
فرمان هدفمند:

```bash
node tests/phase41-atomic-progression-hardening-test.js
```

این آزمون به‌صورت خودکار در `npm run test:static` نیز اجرا می‌شود.

## محدودیت شواهد
این فاز آزمون قراردادهای منبع را اضافه می‌کند؛ اجرای واقعی IndexedDB در مرورگر، آزمون هم‌زمانی چند تب، ساخت APK و آزمایش روی دستگاه واقعی را جایگزین نمی‌کند. بنابراین، این فاز به‌تنهایی مجوز مهاجرت یا انتشار نهایی نیست.
