# فاز ۴۳ — دروازهٔ اعتبارسنجی ساخت APK اندروید

## هدف
بررسی واقعی محیط ساخت اندروید، اجرای مسیر preflight و تلاش برای ساخت APK دیباگ؛ تفکیک دقیق «آمادگی پیکربندی» از «ساخت موفق فایل APK».

## نتیجهٔ اجرای این محیط

| مورد | نتیجه | توضیح |
|---|---|---|
| نسخهٔ اصلی پروژه و `versionName` | موفق | هر دو روی `1.0.0` هستند. |
| پیکربندی Android Gradle Plugin و نسخهٔ Gradle در CI | موفق | نسخه‌ها در فایل‌های پروژه/CI تثبیت شده‌اند. |
| JDK | موفق | Java 21 موجود است و شرط حداقل نسخه را برآورده می‌کند. |
| Gradle محلی | مسدود | دستور `gradle` در محیط موجود نیست. |
| Android SDK | مسدود | `ANDROID_HOME` و `ANDROID_SDK_ROOT` تنظیم نشده‌اند. |
| ابزارهای `adb` و `sdkmanager` | مسدود | در PATH موجود نیستند. |
| اجرای ساخت APK | متوقف‌شده به‌درستی | `npm run android:build:debug` با کد خروج ۲ متوقف شد؛ پیش از اجرای Gradle واقعی، دروازهٔ strict کمبود ابزارها را تشخیص داد. |
| فایل APK | تأییدنشده | APK واقعی ساخته نشد؛ هیچ فایل APK یا نصب روی گوشی ادعا نمی‌شود. |
| آزمون مرورگر IndexedDB | هنوز تأییدنشده | فاز ۴۲ به دلیل سیاست مدیریتی Chromium گزارش `ERR_BLOCKED_BY_ADMINISTRATOR` ثبت کرد. |

## تغییرات این فاز
- افزوده‌شدن آزمون قراردادی `tests/phase43-android-apk-validation-gate-test.js`.
- اتصال آزمون فاز ۴۳ به `npm run test:static`.
- ثبت نتیجهٔ محیطی و محدودیت‌ها در این گزارش و `CHANGELOG.md`.
- هیچ تغییر خطرناکی در مرجع ذخیره‌سازی انجام نشد؛ `automaticMigration` و `dualWrite` خاموش باقی می‌مانند.

## گام‌های لازم برای تأیید APK واقعی
۱. در یک رایانه با Android SDK، platform 36، Build Tools مناسب، JDK سازگار و Gradle 8.13 نصب/در دسترس، پروژه را باز کنید.
۲. از ریشهٔ پروژه اجرا کنید: `npm ci` (اگر lockfile معتبر موجود است؛ در غیر این صورت وابستگی‌ها باید طبق README به‌صورت کنترل‌شده نصب شوند).
۳. اجرا کنید: `npm run android:preflight -- --strict`؛ اگر اسکریپت npm آرگومان را منتقل نکند، دستور مستقیم `node scripts/android-build-preflight.js --strict` را اجرا کنید.
۴. پس از عبور preflight، اجرا کنید: `npm run android:build:debug`.
۵. بررسی کنید فایل `android/app/build/outputs/apk/debug/app-debug.apk` وجود دارد و اندازه‌اش بیشتر از صفر است؛ سپس روی دستگاه/شبیه‌ساز نصب و راه‌اندازی، حفظ داده، ناوبری و به‌روزرسانی را آزمایش کنید.

**وضعیت نهایی:** پیکربندی و گیت‌های ساخت بررسی شدند؛ اما انتشار/نصب اندروید هنوز تأیید نشده است. عبور آزمون‌های ایستا به‌تنهایی معادل APK واقعی یا آزمون گوشی نیست.
