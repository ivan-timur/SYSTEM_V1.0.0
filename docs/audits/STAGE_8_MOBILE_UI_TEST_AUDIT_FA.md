# گزارش مرحلهٔ هشتم — آزمون رابط کاربری موبایل

**نسخهٔ پروژه:** `1.0.0`  
**هدف:** تقویت آزمون‌های ناوبری موبایل و ثبت دقیق محدودیت‌های آزمون مرورگر.

## تغییرات

- افزودن `tests/playwright/mobile-navigation-stability.spec.js` با دو سناریوی مرورگر:
  1. بررسی وجود پنج مقصد ناوبری، اندازه و موقعیت آیکون‌ها و ثابت‌ماندن نوار هنگام پیمایش عمودی.
  2. بررسی قابل‌کلیک‌بودن پنج مقصد در عرض ۳۶۰ پیکسل و نبود سرریز افقی.
- افزودن `tests/mobile-navigation-contract-test.js` برای بررسی ایستای قواعد چیدمان موبایل، پنج مقصد، اندازهٔ آیکون‌ها و فضای امن پایین صفحه.
- افزودن آزمون ایستا به `npm run test:static` و سناریوی جدید به `npm run test:e2e:mobile`.
- نسخهٔ پروژه و قابلیت‌های برنامه تغییر نکرده‌اند.

## نتایج تأییدشده

- `npm run test:static` — موفق؛ همهٔ آزمون‌های ایستا در مجموعه اجرا شدند، ازجمله آزمون جدید ناوبری موبایل.
- `node scripts/project-doctor.js` — نتیجه در گزارش اجرای محیط ثبت شد.
- `node scripts/architecture-guard.js` — نتیجه در گزارش اجرای محیط ثبت شد.
- آزمون ایستای جدید — موفق؛ پنج مقصد، شبکهٔ پنج‌ستونه، ابعاد آیکون و فاصلهٔ امن پایین صفحه بررسی شدند.

## محدودیت مهم

`npm run test:e2e:mobile` اجرا شد، اما پیش از شروع آزمون‌ها متوقف شد؛ وابستگی محلی `@playwright/test` در محیط نصب نیست. بنابراین سناریوهای Playwright در این مرحله **تعریف و به فرمان آزمون متصل شده‌اند، اما در مرورگر واقعی اجرا نشده‌اند**. نتیجهٔ آزمون ایستا جایگزین آزمون واقعی مرورگر نیست.

برای اجرای واقعی در محیط توسعه‌ای با دسترسی نصب وابستگی‌ها:

```bash
npm install
npx playwright install chromium
npm run test:e2e:mobile
```
