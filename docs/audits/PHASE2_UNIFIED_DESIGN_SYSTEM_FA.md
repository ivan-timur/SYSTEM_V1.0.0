# گزارش فاز دوم — Unified Design System

**نسخه:** SYSTEM V1.0.0 — Phase 35  
**دامنه:** زیرساخت طراحی بصری و خط لولهٔ CSS  
**اصل ایمنی:** حفظ رفتار صفحات و منطق اصلی؛ بدون تغییر در XP، مأموریت‌ها، ذخیره‌سازی یا جریان ساخت اندروید.

## تغییرات انجام‌شده

### 1. افزودن لایهٔ توکن‌های معنایی

فایل `css/foundation/design-tokens.css` اضافه شد و در خط لولهٔ رسمی CSS پس از `variables.css` بارگذاری می‌شود. این لایه نام‌های معنایی مشترکی برای سطح‌ها، متن، رنگ تأکیدی، وضعیت‌ها، شعاع گوشه‌ها، فاصله‌ها، تایپوگرافی، حرکت و حلقهٔ فوکوس فراهم می‌کند.

توکن‌های جدید به متغیرهای قدیمی متصل‌اند؛ بنابراین تم‌ها همچنان می‌توانند مقادیر را از متغیرهای موجود به ارث ببرند. این مرحله مهاجرت یک‌بارهٔ همهٔ انتخابگرها نیست؛ هدف ایجاد قرارداد مشترک و سازگار برای مهاجرت تدریجی است.

### 2. اصلاح رفتار ساخت CSS

پیش از این، `scripts/build-css.js` هر `!important` را بی‌صدا حذف می‌کرد. این رفتار حذف شد. اگر در آینده منبعی حاوی `!important` شود، ساخت با پیام خطای مشخص متوقف خواهد شد تا تعارض آبشار به‌صورت آگاهانه حل شود.

در نسخهٔ فعلی، منابع هیچ `!important` ندارند؛ خروجی همچنان بدون آن ساخته می‌شود.

### 3. آزمون قرارداد طراحی

آزمون `tests/design-system-contract-test.js` اضافه شد. آزمون بررسی می‌کند که:

- فایل توکن‌های معنایی در فهرست ساخت باشد؛
- توکن‌های کلیدی در منبع و خروجی موجود باشند؛
- تنظیم کاهش حرکت وجود داشته باشد؛
- اسکریپت ساخت دیگر `!important` را حذف نکند؛
- فایل‌های CSS فهرست‌شده وجود داشته باشند؛
- خروجی فعلی `!important` نداشته باشد.

این آزمون به `test:static` و فرمان مستقل `npm run test:design-system` افزوده شد.

## محدوده و مواردی که هنوز انجام نشده‌اند

- هنوز تمام CSS صفحات به توکن‌های معنایی منتقل نشده‌اند؛ مهاجرت باید صفحه‌به‌صفحه و با مقایسهٔ تصویری انجام شود.
- هنوز بازطراحی کامل کارت‌ها، دکمه‌ها، سایه‌ها و تایپوگرافی اجرا نشده است؛ این فاز قرارداد و پایهٔ مشترک را ایجاد می‌کند.
- آزمون دیداری در مرورگر واقعی، اندازه‌گیری عملکرد روی موبایل و نصب فیزیکی اندروید در این فاز انجام نشده‌اند.
- این فاز تغییر رفتاری در موتور صدا یا الگوریتم اعمال تم‌ها ندارد.

## ارزیابی

فاز دوم از نظر ایجاد لایهٔ توکن‌های معنایی، امن‌ترکردن ساخت CSS و افزودن آزمون قرارداد طراحی تکمیل شده است. پیش از ادعای آمادگی انتشار، اجرای مجموعهٔ کامل آزمون‌ها و آزمون دیداری در مرورگر/اندروید همچنان لازم است.
