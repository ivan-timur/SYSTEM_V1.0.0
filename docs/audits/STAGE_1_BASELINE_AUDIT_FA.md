# گزارش مرحلهٔ اول — تثبیت خط مبنا SYSTEM V1.0.0

**دامنه:** فقط تثبیت خط مبنا، بررسی فراداده‌های نسخه، ثبت وضعیت آزمون‌ها و تطبیق منابع وب با بستهٔ Android. شمارهٔ نسخه تغییر داده نشده است.

## نتیجهٔ فراداده‌های نسخه

- `VERSION`: `1.0.0`
- `package.json`: `1.0.0`
- `manifest.webmanifest`: `1.0.0`
- `sw.js` / `APP_VERSION`: `1.0.0`
- `js/modules/version.js`: `1.0.0`
- `android/app/build.gradle`: `versionName '1.0.0'`, `versionCode 10000000`
- `CHANGELOG.md`: دارای بخش `1.0.0 — Clean V1 Baseline`
- `README.md`: عنوان نسخه با نسخهٔ مرجع هم‌خوان است.

مقدار `versionCode` اندروید عمداً به‌عنوان شمارندهٔ عددی سازگار با مسیر ارتقا حفظ شده است؛ این مقدار معادل متنی نسخه نیست و نباید بدون بررسی سیاست ارتقا تغییر کند.

## تطبیق منابع وب و Android

SHA-256 فایل‌های کلیدی زیر در ریشهٔ وب و `android/app/src/main/assets/www/` برابر است:

- `index.html`
- `VERSION`
- `sw.js`
- `manifest.webmanifest`
- `css/system.css`
- `js/app.js`
- `js/modules/version.js`

مقایسهٔ پوشه‌های کپی‌شونده نیز نتیجهٔ کامل داشت:

| پوشه | فایل‌های وب | فایل‌های Android | مفقود | اضافی | متفاوت |
|---|---:|---:|---:|---:|---:|
| `assets/` | 24 | 24 | 0 | 0 | 0 |
| `css/` | 68 | 68 | 0 | 0 | 0 |
| `js/` | 32 | 32 | 0 | 0 | 0 |
| `dist/` | 18 | 18 | 0 | 0 | 0 |

فهرست Service Worker با 147 ورودی از آزمون امنیت/ساخت عبور کرد؛ منابع precache بررسی‌شده موجود بودند.

- Architecture Guard — موفق

## محدودیت‌های تأیید

- وابستگی‌های npm در محیط بررسی نصب نبودند؛ بنابراین ساخت کامل وابسته به TypeScript و اجرای کامل Playwright انجام نشد.
- APK در این مرحله ساخته و روی دستگاه واقعی نصب نشده است.
- اجرای واقعی Android WebView، اعلان‌ها، حفظ داده پس از ارتقا و آفلاین هنوز تأیید دستگاهی نشده است.

## اصلاح انجام‌شده

در `android/README.md` مثال ثابت و قدیمی `v9.3.2` با یک الگوی عمومی مبتنی بر نسخهٔ مرجع جایگزین شد تا راهنمای انتشار نسخهٔ قدیمی را به‌عنوان نسخهٔ جاری القا نکند.
