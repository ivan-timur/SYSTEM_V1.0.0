# گزارش مرحلهٔ دهم — آماده‌سازی فرمان ساخت و تأیید APK

## دامنه
این مرحله فرمان تکرارپذیر ساخت APK دیباگ را اضافه می‌کند و مسیر تأیید خروجی را روشن می‌سازد. نسخهٔ اصلی پروژه بدون تغییر روی `1.0.0` باقی می‌ماند.

## تغییرات
- فرمان `npm run android:build:debug` اضافه شد.
- پیش‌بررسی سخت‌گیرانهٔ JDK، Gradle، Android SDK، `adb` و `sdkmanager` پیش از ساخت اجرا می‌شود.
- پس از پیش‌بررسی، منابع وب/آفلاین بازسازی و با Android همگام می‌شوند.
- ساخت با `assembleDebug` اجرا می‌شود و وجود APK غیرخالی بررسی می‌شود.
- آزمون قراردادی برای اطمینان از باقی‌ماندن این مراحل در خط ساخت اضافه شد.

## نتیجهٔ محیط فعلی
- Java: موجود؛ نسخهٔ اصلی 21.
- Gradle CLI: موجود نیست.
- `ANDROID_HOME` و `ANDROID_SDK_ROOT`: تنظیم نشده‌اند.
- `adb`: موجود نیست.
- `sdkmanager`: موجود نیست.
- دسترسی شبکه برای دریافت Gradle/Android SDK در محیط آزمایش در دسترس نبود.

به همین دلیل، APK در این محیط ساخته نشد. این گزارش عمداً ساخت یا نصب واقعی APK را ادعا نمی‌کند. فرمان جدید در محیطی که ابزارهای لازم نصب شده باشند، پیش‌بررسی را اجرا کرده و در صورت موفقیت، APK را می‌سازد و مسیر خروجی را تأیید می‌کند.

## اجرای ساخت
از پوشهٔ اصلی پروژه اجرا کنید:

```bash
npm install
npm run android:preflight
npm run android:build:debug
```

خروجی مورد انتظار: `android/app/build/outputs/apk/debug/app-debug.apk`. پس از ساخت، نصب روی دستگاه و آزمون ذخیره‌سازی/آفلاین باید جداگانه انجام شوند.
