# گزارش ارتقای SYSTEM v3.10.0 — فاز دهم: موتور ارزیابی مهارت

## هدف
افزودن هستهٔ ارزیابی قابل‌آزمایش که نتیجهٔ آزمون را در سطح کل آزمون و هر مهارت محاسبه کند، مهارت‌های نیازمند تمرین را مشخص سازد و تکمیل مأموریت را با تسلط اشتباه نگیرد.

## تغییرات
- فایل `src/features/skill-assessment.ts` اضافه شد؛ این موتور مستقل از رابط کاربری و ذخیره‌سازی است.
- اعتبارسنجی شناسه‌ها، پرسش‌های تکراری، گزینه‌ها، کلید پاسخ، پاسخ‌های تکراری و پاسخ‌های نامعتبر انجام می‌شود.
- امتیاز کل و نتیجهٔ هر مهارت محاسبه می‌شود؛ حد قبولی پیش‌فرض ۸۰٪ است و قابل تنظیم است.
- مهارت‌های زیر حد نصاب به‌عنوان نیازمند تمرین مشخص می‌شوند و برایشان توصیهٔ بازبینی و مأموریت عملی تولید می‌شود.
- خروجی شامل `rewardIssued: false` است؛ ارزیابی به‌تنهایی XP، سکه یا پاداش صادر نمی‌کند.
- نسخه به 3.10.0 ارتقا یافت و آزمون جدید به خط آزمون TypeScript افزوده شد.

## آزمون‌های اجراشده
- TypeScript compile (`tsc -p tsconfig.json`): موفق
- آزمون موتور ارزیابی جدید: ۷ assertion موفق
- آزمون Goal Curriculum: ۲۳ assertion موفق
- آزمون قرارداد تأیید مهارت: ۵ assertion موفق
- آزمون Skill Mastery: ۲۷ بررسی موفق
- آزمون Goal Evidence: ۶۰ بررسی موفق

## محدودیت‌ها
- موتور ارزیابی در این فاز به UI متصل نشده و تاریخچهٔ تلاش‌ها را به‌صورت پایدار ذخیره نمی‌کند؛ لایهٔ ذخیره‌سازی باید با تراکنش و کلید یکتای `attemptId` به آن متصل شود.
- موتور، پاسخ‌های صحیح را از تعریف آزمون می‌گیرد؛ آزمون‌های واقعی باید با محتوای معتبر و متناسب با سطح مهارت ساخته شوند.
- امتیاز خودکار به‌تنهایی گواهی مستقل یا هویت‌سنجی ارزیاب نیست.
- آزمون کامل `npm test`، Playwright، ساخت APK و اجرای روی دستگاه انجام نشده‌اند.
