# گزارش ارتقای SYSTEM v3.12.0 — فاز دوازدهم

## هدف
اتصال ردیاب شواهد و تسلط به ذخیره‌سازی دائمی، بدون مخلوط‌کردن ارزیابی خوداظهاری با آزمون‌های امتیازدهی‌شده و بدون تغییر در سیستم پاداش.

## تغییرات
- نسخهٔ پایگاه دادهٔ IndexedDB از ۵ به ۶ ارتقا یافت.
- فروشگاه مستقل `skill_assessments` با شاخص زمان و شناسهٔ ترکیبی مأموریت/مهارت افزوده شد.
- توابع TypeScript برای ذخیرهٔ یکتای رکوردهای ردیاب و خواندن تاریخچه اضافه شدند.
- رابط `SYSTEMDurableSkillAssessments` از ورودی اصلی برنامه به بخش قدیمی رابط کاربری ارائه شد.
- ثبت فرم ردیاب اکنون عملیات ذخیره‌سازی IndexedDB را انتظار می‌کشد و خطای ذخیره را به کاربر گزارش می‌کند.
- داده‌های قدیمی localStorage به‌صورت یک‌طرفه کپی می‌شوند؛ نسخهٔ اصلی حذف نمی‌شود تا مسیر بازیابی حفظ شود.
- فروشگاه آزمون‌های `assessment_attempts` دست‌نخورده و جدا باقی ماند.
- ارزیابی همچنان XP، سکه یا پاداش ایجاد نمی‌کند.

## محدودیت‌ها
- نمره‌ها و شواهد ردیاب، خوداظهاری‌اند و به‌تنهایی اثبات مستقل تسلط نیستند.
- همگام‌سازی با سرور یا میان دستگاه‌ها وجود ندارد؛ IndexedDB محلی همان مرورگر/دستگاه است.
- آزمون مرورگر واقعی و نصب APK تنها در صورت اجرای جداگانهٔ ابزارهای مربوط قابل تأیید است.
