# گزارش ارتقا — SYSTEM v3.13.0
## فاز سیزدهم: موتور مسیر تطبیقی یادگیری

### هدف
ساخت موتور قطعی و قابل‌آزمون برای رتبه‌بندی مأموریت بعدی با استفاده از شواهد مهارت و هدف فعال، بدون تغییر ناخواسته در ذخیره‌سازی یا پاداش‌های موجود.

### تغییرات
- افزوده‌شدن `src/features/adaptive-learning-path.ts` به‌عنوان موتور خالص و تایپ‌شده.
- اولویت‌دهی به مهارت‌های نیازمند تمرین و نمره‌های زیر حدنصاب.
- تشخیص موعد مرور بر اساس تاریخ آخرین ارزیابی و فاصلهٔ مرور مهارت.
- افزایش اولویت مأموریت‌های مرتبط با هدف و نقطهٔ عطف فعال.
- فیلتر مأموریت‌های تکمیل‌شده و مسدودکردن مأموریت‌هایی که پیش‌نیاز مهارت تأییدشده ندارند.
- کنترل شناسه‌های تکراری، تاریخ‌ها، نمره‌ها، دشواری و مدت مأموریت.
- ارائهٔ دلیل قابل‌فهم برای هر پیشنهاد و آمار تشخیصی.
- حفظ `rewardIssued: false`؛ این موتور XP، سکه یا تأیید مهارت صادر نمی‌کند.
- افزودن ۹ assertion جدید و ثبت آزمون آن در چرخهٔ TypeScript.

### مرزهای این فاز
این نسخه موتور پیشنهاددهی و قرارداد آن را فراهم می‌کند. اتصال پیشنهادها به رابط کاربری زنده، خواندن خودکار وضعیت از IndexedDB، نوشتن تاریخچهٔ پیشنهادها و اجرای آزمون مرورگر واقعی هنوز انجام نشده‌اند و نباید به‌عنوان قابلیت تکمیل‌شده تلقی شوند.

### آزمون‌ها
- کامپایل TypeScript و آزمون اختصاصی موتور: موفق.
- اجرای مجموعهٔ کامل `npm test`: پس از هماهنگ‌سازی نسخهٔ مرجع، اجرای کامل `npm test` باید دوباره بررسی شود؛ اجرای اولیه پیش از اصلاح متادیتای نسخه به دلیل ناسازگاری `VERSION` و README متوقف شد.
