# SYSTEM v3.15.0 — فاز شانزدهم: Adaptive Aether

## هدف
ارتقای موتور بصری Canvas با تمرکز بر عمق فضایی، پاسخ‌گویی کنترل‌شده و سازگاری با موبایل؛ بدون تغییر در منطق XP، مأموریت‌ها، مهارت‌ها یا پاداش‌ها.

## ارتقاها
1. **Energy Core:** هستهٔ نورانی کم‌هزینه با چهار گرهٔ مداری و پالس آرام.
2. **Adaptive Motion:** نرخ فریم تزئینی حدود 24 FPS برای موبایل/دستگاه کم‌توان و حدود 30 FPS برای دستگاه‌های دیگر.
3. **Pointer Hygiene:** اثر اشاره‌گر فقط مدت کوتاهی پس از حرکت فعال می‌ماند و هنگام blur غیرفعال می‌شود.
4. **Milestone Resilience:** محدودیت صف اعلان‌ها با ثابت نام‌گذاری‌شده و بازخورد بصری اختصاصی مهارت.
5. **Accessibility:** پشتیبانی reduced-motion حفظ شده و ترنزیشن‌های رابط در این حالت خاموش می‌شوند.

آزمون‌ها باید در محیط پروژه با `npm run build` و `npm run test:static` اجرا شوند. اجرای کامل Playwright و آزمون روی دستگاه واقعی در این گزارش ادعا نمی‌شود.
