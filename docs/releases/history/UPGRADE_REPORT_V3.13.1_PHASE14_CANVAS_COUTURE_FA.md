# SYSTEM v3.13.1 — Phase 14: Canvas Couture (3-stage visual upgrade)

## هدف
ارتقای عمیق انیمیشن، Canvas، تعامل‌های ظریف و بازخورد رویدادها، بدون دست‌زدن به منطق XP، مهارت‌ها، مأموریت‌ها یا ذخیره‌سازی پیشرفت.

## مرحلهٔ ۱ — هستهٔ Canvas و کارایی
- نرخ رندر با ثابت `FRAME_INTERVAL` روی حدود ۳۰ فریم در ثانیه محدود شده است.
- گام حرکت ذرات بر اساس زمان فریم تعدیل می‌شود تا افت فریم، سرعت انیمیشن را به‌هم نریزد.
- نسبت پیکسل و تراکم ذرات برای دستگاه‌های کم‌توان کاهش می‌یابد؛ موبایل همچنان سبک باقی می‌ماند.
- تغییر اندازهٔ پنجره با `requestAnimationFrame` تجمیع می‌شود تا resizeهای پیاپی رندرهای اضافی نسازند.

## مرحلهٔ ۲ — عمق بصری و تعامل
- درخشش ذرات ضربان نرم‌تر و متنوع‌تری دارد.
- حرکت اشاره‌گر دسکتاپ، ذرات نزدیک را بسیار ملایم جابه‌جا می‌کند؛ لمس موبایل وارد این تعامل نمی‌شود.
- محدودیت تعداد burstها حفظ شده تا جلوه‌های پی‌درپی منابع را اشغال نکنند.
- بازخورد milestone با درخشش کوتاه، پس‌زمینهٔ عمیق‌تر و قاب نئونی‌تر ارتقا یافته است.

## مرحلهٔ ۳ — دسترس‌پذیری و پایداری
- `prefers-reduced-motion` همچنان Canvas و انیمیشن تزئینی را خاموش می‌کند.
- Canvas همچنان `aria-hidden`، بدون دریافت کلیک و مستقل از منطق پیشرفت است.
- فایل‌های اصلی و نسخهٔ همگام Android هر دو به‌روزرسانی شده‌اند.
- آزمون قراردادی جلوه‌ها برای بررسی کنترل کیفیت، تعامل اشاره‌گر، resize و سبک‌سازی دستگاه به‌روزرسانی شد.

## فایل‌های تغییر یافته
- `js/modules/visual-effects.js` و نسخهٔ همگام Android
- `css/features/visual-effects.css` و نسخهٔ همگام Android
- `tests/visual-effects-contract-test.js`

## نکتهٔ اعتبارسنجی
این بسته بر پایهٔ پروژهٔ ارائه‌شده ساخته شده است. اجرای کامل تست‌های پروژه به Node.js و وابستگی‌های نصب‌شده نیاز دارد؛ در محیط بستهٔ فعلی ادعای اجرای کامل تست‌ها نشده است.
