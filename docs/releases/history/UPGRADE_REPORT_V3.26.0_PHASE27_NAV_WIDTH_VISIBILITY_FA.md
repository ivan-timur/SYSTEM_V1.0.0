# گزارش فاز ۲۷ — اصلاح ریشه‌ای ناوبری موبایل

## نشانهٔ مشاهده‌شده
در تصویر گوشی، پس‌زمینهٔ نوار پایین تمام عرض صفحه را می‌پوشاند اما فقط Status و Quest در بخش چپ دیده می‌شوند؛ فضای مربوط به Rewards، AI و Settings خالی می‌ماند.

## تغییرات
- بازنویسی قواعد موبایل در انتهای فایل CSS نهایی `css/system.css` تا بر قواعد قدیمی و تم‌ها اولویت داشته باشند.
- تثبیت عرض نوار کناری روی `100vw` و حذف حداقل عرض دسکتاپ در موبایل.
- اجبار `.sidebar-nav` به شبکهٔ پنج‌ستونه با عرض کامل و بدون محدودیت عرض ذاتی.
- تثبیت نمایش، اندازه و جهت هر پنج دکمه و تصویر آیکون.
- حفظ ناحیهٔ امن Android از طریق `env(safe-area-inset-bottom)`.

## اعتبارسنجی
این اصلاح بر اساس ساختار DOM و CSS پروژه انجام شده است. برای تأیید نهایی باید نسخه روی همان گوشی/مرورگر پیش‌نمایش اجرا شود؛ در این محیط امکان تأیید تصویری واقعی روی دستگاه اندرویدی وجود ندارد.
