# گزارش ارتقای SYSTEM v3.1.0 — جلوه‌های بصری و انیمیشن

## هدف

پیاده‌سازی بخش «Canvas / WebGL — جلوه‌های بصری و انیمیشن» از نقشهٔ معماری نهایی، با کمترین خطر برای منطق بازی، ذخیره‌سازی و سازگاری Android.

## تغییرات سورس

- `js/modules/visual-effects.js`: ماژول مستقل جلوه‌های تزئینی Canvas؛ ذرات آرام، پیوندهای بسیار کم‌رنگ و حلقهٔ بازخورد اختیاری برای رویدادهای تکمیل مأموریت، ارتقای Level و بازشدن Achievement.
- `css/features/visual-effects.css`: لایهٔ micro-interaction با تغییرات غیرمتحرک‌ساز چیدمان و قوانین موبایل/کاهش حرکت.
- `scripts/build-css.js`: اضافه‌شدن قطعهٔ CSS به فرایند رسمی ساخت؛ فایل `css/system.css` همچنان خروجی تولیدی است.
- `js/app.js`: مقداردهی اولیهٔ ماژول پس از بارگذاری موفق برنامه.
- `tests/visual-effects-contract-test.js`: آزمون قراردادی برای دسترس‌پذیری، محدودیت عملکرد، عدم دسترسی به ذخیره‌سازی/شبکه و اتصال runtime.
- `scripts/architecture-guard.js`, `docs/ARCHITECTURE_ROADMAP_FA.md`, `docs/ARCHITECTURE.md`, `README.md`, `CHANGELOG.md`: ثبت مسئولیت و محدودیت‌های این لایه.

## تصمیم‌های عملکرد و دسترس‌پذیری

- `prefers-reduced-motion: reduce` باعث خاموش‌ماندن Canvas می‌شود.
- انیمیشن در زمان مخفی‌بودن صفحه متوقف می‌شود.
- DPR به حداکثر 1.5 و نرخ ترسیم به حدود 30 FPS محدود شده است.
- تعداد ذرات در موبایل پایین‌تر است؛ Canvas به رویدادهای لمس/کلیک راه نمی‌بندد.
- ماژول هیچ XP، Level، Rank، Quest یا اطلاعات ذخیره‌شده‌ای را تغییر نمی‌دهد و درخواست شبکه‌ای ندارد.
- WebGL اضافه نشده؛ برای جلوهٔ دوبعدی سبک فعلی، هزینه و پیچیدگی آن توجیه ندارد.

## آزمون‌ها و ساخت

- `npm test`: موفق؛ ساخت، آزمون‌های TypeScript، آزمون‌های ایستا و نگهبان معماری تکمیل شدند.
- `npm run doctor`: موفق.
- `npm run prepare:android`: موفق؛ 138 فایل وب در دارایی‌های Android همگام شد (حدود 6.03 MiB).
- آزمون قراردادی تازهٔ جلوه‌های بصری: موفق.
- Playwright مرورگر در محیط موجود نصب نبود؛ بنابراین آزمون بصری تعاملی/اسکرین‌شات در مرورگر اجرا نشده است.
- APK واقعی در این مرحله ساخته نشده است؛ همگام‌سازی دارایی‌ها به معنی کامپایل APK نیست.

## سازگاری

کلیدهای ذخیره‌سازی و قوانین XP/Level/Rank/Quest دست‌نخورده‌اند. این نسخه فقط لایهٔ نمایشی و مسیر ساخت را توسعه می‌دهد.
