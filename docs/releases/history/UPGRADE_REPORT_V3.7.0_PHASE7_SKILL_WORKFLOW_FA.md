# گزارش ارتقای SYSTEM v3.7.0 — فاز هفتم: گردش‌کار شواهد مهارت

## هدف
این فاز رابط ردیاب تسلط را از ارزیابی صرفاً بر اساس شاخهٔ کلی به ثبت ارزیابی برای یک مهارت مشخص ارتقا می‌دهد. هدف، بهترشدن قابلیت پیگیری یادگیری است؛ نه ادعای صدور گواهی مستقل.

## تغییرات
- فرم ارزیابی مهارت اکنون نام دقیق مهارت و شناسهٔ پایدار آن را در کنار شاخه، نوع ارزیابی، نمره و وجود شواهد می‌گیرد.
- API ردیاب تسلط، شناسه و عنوان مهارت را اعتبارسنجی و ذخیره می‌کند؛ رکوردهای قدیمی بدون این فیلدها همچنان قابل‌خواندن هستند.
- خلاصهٔ جداگانه برای هر مهارت اضافه شد؛ وضعیت‌ها عبارت‌اند از «در حال یادگیری»، «شواهد ثبت‌شده» و «آمادهٔ بازبینی».
- وضعیت «آمادهٔ بازبینی» تنها یک نشانگر بر پایهٔ نمره‌های خوداظهاری و شواهد ثبت‌شده است و به‌عنوان تسلط تأییدشده معرفی نمی‌شود.
- تاریخچهٔ ارزیابی نام مهارت و شاخهٔ آن را نمایش می‌دهد.
- ارزیابی همچنان XP، سکه یا رتبه صادر نمی‌کند؛ مسیر پاداش تغییر نکرده است.
- آزمون‌های رگرسیون برای شناسهٔ مهارت، عنوان، وضعیت شواهد، شناسهٔ نامعتبر و متن رابط افزوده شدند.

## محدودیت‌های شناخته‌شده
- این نسخه هنوز تأییدکنندهٔ انسانی را احراز هویت نمی‌کند و ارزیابی‌های واردشده در مرورگر، خوداظهاری‌اند.
- نتیجهٔ «آمادهٔ بازبینی» گواهی مهارت نیست و به موتور پاداش متصل نشده است.
- رابط هنوز به آزمون‌های تعاملی اختصاصی برای هر Skill از درخت مهارت متصل نشده؛ کاربر نام و شناسهٔ مهارت را وارد می‌کند.
- اجرای آزمون‌های E2E واقعی مرورگر و ساخت/اجرای APK فقط در صورت وجود ابزارهای لازم قابل تأیید است؛ این گزارش آن‌ها را ادعا نمی‌کند.

## اعتبارسنجی
نتایج اجراشده برای این بسته: `npm test` موفق شد؛ `npm run doctor` نیز موفق شد. بررسی معماری، آزمون‌های TypeScript و آزمون‌های ایستا همگی موفق بودند. ابزار Playwright در محیط نصب نبود، پس آزمون E2E مرورگر اجرا نشد. APK ساخته یا روی دستگاه اجرا نشده است.
