# گزارش ارتقا — SYSTEM v3.8.0 (Phase 8)

## هدف
پیوند دادن ثبت شواهد مهارت به درخت رسمی مهارت‌ها، به‌جای واردکردن دستی نام و شناسهٔ مهارت.

## تغییرات
- فهرست مهارت‌ها از `SYSTEMSkillCurriculum` خوانده می‌شود؛ انتخاب شاخه، مهارت‌های همان شاخه را بارگذاری می‌کند.
- فرم ردیاب تسلط، نام و شناسهٔ پایدار مهارت را از کاتالوگ رسمی پر می‌کند.
- شناسهٔ مأموریت مرتبط به‌صورت اختیاری کنار ارزیابی ذخیره و در تاریخچه نمایش داده می‌شود.
- از ثبت دوبارهٔ شواهد برای ترکیب یکسانِ شناسهٔ مهارت + شناسهٔ مأموریت جلوگیری می‌شود.
- قالب ارزیابی‌های قدیمی بدون `skillId` یا `questId` همچنان پذیرفته می‌شود؛ مهاجرت مخرب انجام نمی‌شود.
- این مسیر به‌خودی‌خود XP، سکه یا تکمیل مأموریت ایجاد نمی‌کند.

## مرزهای صداقت و محدودیت‌ها
- واردکردن Quest ID به‌تنهایی ثابت نمی‌کند که مأموریت واقعاً تکمیل شده است؛ اتصال به وضعیت قطعی همهٔ انواع مأموریت‌ها هنوز نیازمند یکپارچه‌سازی مجزا است.
- وضعیت «آمادهٔ بازبینی» تأیید مستقل تسلط نیست؛ نمره‌ها و شواهد فعلاً خوداظهاری‌اند.
- این نسخه ادعا نمی‌کند که آزمون مرورگر Playwright، ساخت APK یا آزمایش روی دستگاه اندرویدی انجام شده است.
