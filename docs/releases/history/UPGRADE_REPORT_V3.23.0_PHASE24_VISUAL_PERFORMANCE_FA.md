# گزارش ارتقای SYSTEM v3.23.0 — فاز ۲۴: بهینه‌سازی عملکرد بصری

## تغییرات پیاده‌سازی‌شده
- حالت کم‌مصرف تطبیقی برای دستگاه‌های دارای حافظه/هسته محدود یا `Save-Data` فعال شد.
- سقف نرخ اجرای Canvas در حالت کم‌مصرف به حدود ۲۰ فریم در ثانیه محدود شد؛ موبایل عادی همچنان از محدودیت ۲۴ و دسکتاپ مناسب از ۳۰ فریم استفاده می‌کند.
- نسبت پیکسل Canvas در حالت کم‌مصرف به ۱ محدود شد تا هزینهٔ رندر کاهش یابد.
- تعداد ذرات در حالت کم‌مصرف کاهش یافت و خطوط جفتیِ پرهزینه روی موبایل/دستگاه کم‌مصرف حذف شدند.
- لایه‌های مداری تزئینی در صفحه‌های کوچک یا حالت کم‌مصرف به یک لایه کاهش یافتند.
- تعداد افکت‌های انفجاری هم‌زمان در حالت کم‌مصرف محدود شد.
- snapshot تشخیصی عملکرد شامل هزینهٔ آخرین فریم، میانگین هموارشده، شمار ذرات، حالت کم‌مصرف، فاصلهٔ فریم و وضعیت کاهش حرکت اضافه شد.
- CSS فاز ۲۴ برای موبایل و `prefers-reduced-motion` اضافه شد؛ در موبایل blur سنگین حذف می‌شود و حالت کاهش حرکت، انیمیشن‌ها و transitionهای تزئینی را خاموش می‌کند.
- آزمون قراردادی جدید برای کنترل قواعد بهینه‌سازی اضافه شد.

## مرزهای اعتبارسنجی
این فاز محدودیت‌ها و تشخیص‌های عملکردی را در کد پیاده می‌کند. عدد FPS واقعی، مصرف باتری و زمان فریم روی گوشی فیزیکی در این محیط اندازه‌گیری نشده‌اند. برای تأیید میدانی باید با DevTools/Android WebView روی دستگاه‌های مختلف پروفایل‌گیری انجام شود.
