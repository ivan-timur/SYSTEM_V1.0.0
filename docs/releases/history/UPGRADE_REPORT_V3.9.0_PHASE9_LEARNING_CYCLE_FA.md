# گزارش ارتقای SYSTEM v3.9.0 — فاز نهم: اتصال چرخهٔ یادگیری

## هدف
اتصال شناسهٔ مهارت مأموریت تکمیل‌شده به دفتر شواهد هدف، بدون اشتباه گرفتن انجام مأموریت با اثبات تسلط بر مهارت و بدون تغییر مسیر اعطای پاداش.

## تغییرات
- هنگام تکمیل Custom Quest، شناسهٔ پایدار مهارتِ مأموریت در `goalEvidence` حفظ می‌شود.
- `SYSTEMGoalProgress` شناسهٔ مهارت را در شواهد ذخیره و در نمای سازگارشدهٔ Goal Curriculum منتقل می‌کند.
- برای شواهد قدیمی و جدیدِ مأموریت، `skillVerification` به‌صورت صریح خالی می‌ماند مگر آن‌که ارزیابی مستقل ثبت شده باشد؛ بنابراین صرف تکمیل Quest مهارت را تأیید نمی‌کند.
- مسیر ثبت شواهد همچنان یکتا است و تکرار همان Quest پیشرفت یا پاداش جدید ایجاد نمی‌کند.
- کلیدهای ذخیره‌سازی قدیمی و ظاهر رابط کاربری تغییر نکرده‌اند.
- نسخهٔ برنامه به 3.9.0 ارتقا یافت.

## محدودیت‌های صریح
- Goalهای قدیمی همچنان از مدل هدف‌گذاری مبتنی بر تعداد شواهد استفاده می‌کنند؛ ویرایشگر کامل milestone و الزام مهارت به‌ازای هر milestone در این فاز ادعا نمی‌شود.
- امتیاز ارزیابی خوداظهاری، گواهی مستقل یا هویت‌سنجی ارزیاب نیست.
- آزمون E2E مرورگر، ساخت APK و اجرای واقعی روی دستگاه در این محیط تأیید نشده‌اند.

## اعتبارسنجی
آزمون‌های ایستای مرتبط با Goal Progress و Skill Mastery باید پس از دریافت وابستگی‌های پروژه اجرا شوند. این محیط بستهٔ `node_modules` ندارد؛ بنابراین اجرای کامل `npm test` انجام نشده است.
