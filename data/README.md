# داده‌های مرجع و seed

این JSONها در نسخهٔ فعلی SYSTEM منبع runtime نیستند؛ برنامه تعریف‌های فعال را از HTML و JavaScript می‌گیرد. فایل‌های این پوشه برای مستندسازی شکل داده و آماده‌سازی مهاجرت آینده باقی مانده‌اند. تغییرشان به‌تنهایی رابط برنامه را تغییر نمی‌دهد. پیش از استفادهٔ runtime باید schema، اعتبارسنجی، migration/versioning و آزمون سازگاری تعریف شود.
